## 摘要
预测单细胞对遗传和化学扰动的响应，对于理解调控机制和优先排序治疗干预具有重要意义。现有方法通过神经网络、图先验、基础模型表示或分布生成模型来建模扰动条件化的表达变化，已取得进展。然而，组合扰动预测仍具挑战性，因为响应中的很大一部分可由单扰动的加性效应解释，而具有生物学信息量的信号往往位于由扰动交互诱导的较小的非加性残差中。因此，直接生成完整的扰动后表达谱可能会将大量容量分配给占主导的加性成分，而低估协同特异性结构。为解决该问题，我们提出 SynGeneFlow，一个协同感知的流匹配框架，其将源分布锚定在加性先验上，并学习指向真实扰动状态的残差流。SynGeneFlow 进一步引入扰动条件化的基因交互建模，其中静态基因-基因掩码提供生物结构，而扰动依赖的形变偏置动态调节基因-基因耦合。为保留群体水平的响应结构，我们使用基于 MMD 的正则化对端点分布和生物残差分布进行对齐。我们在观测单扰动、留出和跨模态设置下，在遗传和药物扰动基准上评估 SynGeneFlow。结果表明，围绕加性扰动效应对流匹配进行残差化，为单细胞扰动响应预测提供了一个具有生物学依据且稳健的框架。

## Abstract
Predicting single-cell responses to genetic and chemical perturbations is important for understanding regulatory mechanisms and prioritizing therapeutic interventions. Existing methods have made progress by modeling perturbation-conditioned expression shifts with neural networks, graph priors, foundation-model representations, or distributional generative models. However, combinatorial perturbation prediction remains challenging because much of the response can be explained by additive single-perturbation effects, while the biologically informative signal often lies in a smaller non-additive residual induced by perturbation interactions. Directly generating the full post-perturbation expression profile may therefore allocate substantial capacity to the dominant additive component and underemphasize synergy-specific structure. To address this issue, we propose \textbf{SynGeneFlow}, a synergy-aware flow matching framework that anchors the source distribution at an additive prior and learns a residual flow toward the true perturbed state. SynGeneFlow further incorporates perturbation-conditioned gene interaction modeling, where a static gene-gene mask provides biological structure and a perturbation-dependent deformation bias dynamically modulates gene-gene coupling. To preserve population-level response structure, we align both endpoint distributions and biological residual distributions with MMD-based regularization. We evaluate SynGeneFlow on genetic and drug perturbation benchmarks under observed-single, held-out, and cross-modality settings. The results demonstrate that residualizing flow matching around additive perturbation effects provides a biologically grounded and robust framework for single-cell perturbation response prediction.

## 1. 核心问题与研究动机

- **背景意义**：单细胞层面预测细胞对基因/化学扰动的响应，是功能基因组学、药物发现与治疗靶点优先级排序的核心问题。组合扰动空间随扰动数量指数增长，实验上无法穷举，因此需要能从已观测扰动泛化到未见组合的 in silico 模型。
- **关键矛盾**：近期基准显示，简单的均值/加性基线在组合扰动预测上表现意外强劲，说明响应中很大一部分可由单扰动的加性效应解释；但真正具有生物学意义的信号往往位于较小的**非加性残差**中，即扰动间交互产生的**协同效应**。
- **现有方法不足**：直接生成完整扰动后表达谱的模型（包括扩散/流匹配类生成模型）可能将大量容量分配给占主导的加性成分，而低估协同特异性结构；许多组合方法隐式或近似加性地组合扰动。
- **数据层面挑战**：单细胞测序具有破坏性，扰动前后细胞无法配对，数据本质非配对；表达谱稀疏、零膨胀、受 dropout 与批次/测序深度影响；扰动效应非线性且上下文依赖。
- **基因交互建模不足**：静态共表达图只反映平均依赖模式，同一对基因在不同扰动上下文下的有效耦合可能增强、减弱或重定向，固定图或独立基因特征难以刻画动态调控重连。
- **整体含义**：论文主张将流匹配的源分布锚定在加性先验上，让生成模型专注于学习非加性协同残差，并结合扰动条件化的基因交互建模与分布对齐，从而更生物合理地预测组合扰动响应。

## 2. 方法论：SynGeneFlow 框架

### 2.1 核心思想

- 不将噪声直接传输到完整扰动后表达谱，而是先构造**加性先验**（控制表达 + 估计的单扰动效应之和），再学习从加性先验到真实扰动状态的**残差流**，该残差对应无法由独立扰动效应解释的非加性协同。
- 在表示层面引入**扰动条件化的基因交互建模**：静态基因-基因掩码提供生物结构，扰动依赖的形变偏置动态调节基因间耦合。
- 在分布层面使用 **MMD 双重对齐**：同时对齐终点表达分布与生物协同残差分布。

### 2.2 协同残差流匹配

- 加性算子：
  - \(A(c_x,c_p)=c_x+\sum_{j\in \mathrm{supp}(c_p)}\delta_j\)，其中 \(\delta_j=g_\phi(e_{p_j},c_x)\) 为可学习的单扰动效应解码器输出。
  - 多扰动时对各活跃扰动效应求和；若缺少单扰动谱，则通过扰动嵌入外推。
- 随机加性锚点：
  - \(z_0=A(c_x,c_p)+\epsilon\)，\(\epsilon\sim q_\tau(\epsilon|c_x)\)，\(\tau\) 控制噪声幅度；\(\tau=0\) 退化为确定性加性源。
- 插值路径与参考速度：
  - \(x_t=(1-t)z_0+t x_1\)，\(t\sim U(0,1)\)。
  - 随机传输残差 \(s_\tau=x_1-A(c_x,c_p)-\epsilon\)，作为速度监督目标。
  - 生物协同残差 \(s=x_1-A(c_x,c_p)\)，用于残差分布对齐。
- 流匹配损失：
  - \(\mathcal{L}_{\mathrm{SFM}}=\mathbb{E}\|v_\theta(x_t,t,c_x,c_p)-s_\tau\|_2^2\)。
- 单扰动一致性损失：
  - \(\mathcal{L}_{\mathrm{single}}=\mathbb{E}_{a\in\mathcal{P}^{\mathrm{train}}_{\mathrm{single}}}\|A(c_x,\{a\})-x_1^{(a)}\|_2^2\)，防止加性算子吸收非加性效应。

### 2.3 双重分布对齐

- 一步端点近似：\(\hat{x}_1=x_t+(1-t)v_\theta(x_t,t,c_x,c_p)\)。
- 预测协同残差：\(\hat{s}=\hat{x}_1-A(c_x,c_p)\)。
- 两个 MMD 项：
  - \(\mathcal{L}^{\mathrm{end}}_{\mathrm{MMD}}=\mathrm{MMD}^2(\{\hat{x}_1\},\{x_1\})\)。
  - \(\mathcal{L}^{\mathrm{syn}}_{\mathrm{MMD}}=\mathrm{MMD}^2(\{\hat{s}\},\{s\})\)。
- 多核高斯 RBF 混合核，带宽由 mini-batch 成对距离自适应估计。
- 总目标：\(\mathcal{L}=\mathcal{L}_{\mathrm{SFM}}+\lambda_1\mathcal{L}^{\mathrm{end}}_{\mathrm{MMD}}+\lambda_2\mathcal{L}^{\mathrm{syn}}_{\mathrm{MMD}}+\lambda_3\mathcal{L}_{\mathrm{single}}\)。

### 2.4 扰动条件化基因编码

- 每个基因作为 token；基因身份编码器与标量值编码器生成对齐 token 序列。
- 静态基因-基因先验由训练数据绝对 Pearson 相关构造，经 kNN 保留强相关邻居，得到稀疏邻接矩阵并转为注意力掩码 \(M_{ij}\)。
- 扰动条件形变偏置：
  - \(a^p_{ij}=\frac{q_i^\top k_j}{\sqrt{d}}+M_{ij}+\Delta^p_{ij}\)。
  - \(\Delta^p_{ij}=w_\psi^\top\sigma(W_\psi[h_i\|h_j\|e_p]+b_\psi)\)。
  - 掩码定义生物合理交互空间，形变偏置在当前扰动下动态调节边强度。
- 最终细胞 token 融合结构表示与表达值嵌入。

### 2.5 扰动感知速度 Transformer

- 输入：中间态 token、控制 token、扰动嵌入、时间嵌入。
- 每层先通过 MLP 注入扰动条件，再经自注意力与对控制表示的交叉注意力精炼；可实现为差分注意力以抑制共享噪声模式。
- 最终解码为速度场，用于预测随机传输残差。

### 2.6 训练与推理

- 训练：mini-batch 三元组 \((c_x,c_p,x_1)\)；可在选定基因子集 \(I\) 上计算所有损失项。
- 推理：采样同类随机加性锚点 \(X_0=A+\epsilon\)，从 \(t=0\) 到 \(t=1\) 用 Euler 步积分；给定 \(X_0\) 后 ODE 轨迹确定。
- 计算复杂度：基因编码器与速度 Transformer 每层 \(O(N_I^2)\)；形变偏置仅在保留边上计算 \(O(E_I d_\psi)\)；MMD 为 \(O(B^2)\)。

## 6. 主要结论与发现

- **Additive split（Norman）**：SynGeneFlow 全面优于 scDFM，L2 从 1.7043 降至 1.6736，MSE 从 0.00315 降至 0.00296，MAE 从 0.02155 降至 0.02091；DE-Spearman 从 0.5705 升至 0.5928，Pearson \(\Delta\) 从 0.8853 升至 0.9086，DS 从 0.9737 升至 0.9779。说明加性先验锚定有助于恢复扰动响应方向、DE 结构与群体可分性。
- **Holdout single（Norman）**：除 DS 外全面最佳；L2 从 1.6186 降至 1.5482，DE-Spearman 从 0.6957 升至 0.7248，Pearson \(\hat{\Delta}_{20}\) 从 0.8116 升至 0.8462。
- **Holdout double（Norman）**：优势更明显；L2 从 2.0309 降至 1.8846，DE-Spearman 从 0.5676 升至 0.6312，Pearson \(\hat{\Delta}\) 从 0.7769 升至 0.8136；但 DS 仍略低于 scDFM。
- **非加性协同预测**：Synergy MSE 从 0.00488 降至 0.00391，Synergy Pearson 从 0.487 升至 0.573，Synergy DE-Spearman 从 0.438 升至 0.526，Non-additive Recall@50 从 0.462 升至 0.548。表明增益不仅来自端点拟合，而是更有效隔离并建模非加性残差。
- **ComboSciPlex 药物迁移**：优于 scDFM，MAE 从 0.0220 降至 0.0207，DE-Spearman 从 0.8289 升至 0.8618，Pearson \(\Delta\) 从 0.8933 升至 0.9146；DS 高于 scDFM 但低于 CPA，说明残差流在化学扰动模态下仍具迁移性。
- **消融结论**：去掉加性先验、去掉单扰动一致性损失、去掉任一 MMD 项、去掉形变偏置或基因掩码、用标准注意力替代差分注意力，均导致主要指标下降；其中 synergy-residual MMD 的移除对 DE-Spearman 与 Pearson \(\hat{\Delta}_{20}\) 影响较大，支持残差分布对齐的必要性。

- **方法设计有层次**：加性先验 + 残差流匹配、单扰动一致性约束、双重 MMD 对齐、静态图 + 扰动条件形变偏置，各组件分别对应不同失败模式。

- **生物先验使用克制且可解释**：静态共表达图只作为交互掩码，扰动条件形变偏置在其上调节边强度，既避免完全依赖固定图，也避免让模型从零学习所有基因耦合。

- **实验叙事完整**：从 observed-single 到 held-out single/double，再到跨模态药物迁移，并补充协同专项与消融，能够较系统地支撑“残差化建模有效”的主论点。

- **评估指标存在不一致**：DS 在 holdout single/double 上并非全面领先，说明群体可分性与表达重建/响应相关性并非同一目标；论文对这些指标冲突的讨论不足。
- **生物机制解释有限**：协同残差与形变偏置虽具生物直觉，但缺少对关键基因、通路或边重连的可解释性分析，也缺少湿实验或独立外部数据验证。
- **静态图先验的简化**：Pearson 相关图只刻画平均共表达关系，可能遗漏上下文特异、方向性或因果调控关系；形变偏置能否充分恢复动态重连仍需更强证据。
- **消融解读需谨慎**：消融多以相对百分比呈现，部分变体间绝对差异较小；不同组件之间可能存在耦合，单独移除某一项的下降不一定能完全归因于该组件。

## 9. 可改进方向

- **强化统计与复现实验**：报告多随机种子下的均值、方差与置信区间，补充配对显著性检验，并公开完整超参数、训练配置与推理步数。
- **增加超参数与鲁棒性分析**：系统扫描损失权重、噪声尺度、Euler 步数、基因子集规模和图稀疏度；评估单扰动缺失比例、低质量扰动谱和外推场景下的性能退化。
- **扩展数据与场景**：覆盖更多细胞系、物种、药物剂量/时间序列和多扰动高阶组合；引入独立外部验证集，检验跨数据集泛化。
- **改进先验建模**：对加性先验引入不确定性估计或误差校正项，区分“先验估计误差”和“真实协同残差”；探索动态图先验、因果/调控先验或扰动特异性图结构。
- **提升可解释性**：分析形变偏置中高权重基因对与通路，结合差异表达和协同基因模块解释预测依据；对关键预测进行扰动或边消融验证。
- **优化计算效率**：研究稀疏注意力、低秩 MMD 近似、少步或蒸馏采样，降低 ODE 推理成本，并报告实际 GPU 资源与训练时长。
- **统一评估视角**：进一步讨论重建指标、响应相关指标、DE 排序与 DS 之间的权衡，必要时给出面向协同发现的任务特定指标与校准分析。

## 10. 总体评价

SynGeneFlow 的核心贡献在于把组合扰动预测从“直接生成完整表达谱”重构为“以加性先验为锚、学习非加性协同残差”，并在表示层和分布层分别加入扰动条件化基因交互与双重 MMD 对齐。该设计问题动机清晰、组件与失败模式对应较好，实验上在多个设置中优于直接流匹配基线 scDFM，尤其在 held-out double 与非加性协同专项上表现更明显。与此同时，论文在统计严谨性、超参数敏感性、计算成本、数据覆盖和生物可解释性方面仍有提升空间；其结论更适合理解为“残差化建模范式具有较强潜力”，而非已经充分证明其在广泛场景下稳定优越。总体而言，这是一项方法思路有新意、实验叙事较完整、但仍需更强复现与外部验证支撑的工作。
