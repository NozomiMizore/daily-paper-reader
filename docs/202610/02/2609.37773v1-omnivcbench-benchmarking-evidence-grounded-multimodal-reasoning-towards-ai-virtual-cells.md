## 摘要
人工智能虚拟细胞（AIVCs）被设想为科学智能体，能够模拟细胞响应、解释潜在机制，并支持假设驱动的发现。然而，现有 AIVC 基准主要在模拟层面运行，这促使我们需要补充评估模型如何解读实验证据并形成生物学假设。我们提出 OmniVCBench，一个以图表为中心、来源可追溯的基准，用于评估 AIVC 的解释组件。它包含 6,077 个经过整理的单一和多个子图问答对，这些问答对源自科学文献中的图表和实验背景。在 Bloom 分类法的指导下，我们通过三项科学推理任务，将 AIVC 的“预测—解释—发现”议程实例化为解释层面的对应任务。我们进一步提出 AIVC-Judge，一种任务条件化的 MLLM-as-a-judge 框架，具有类别特定、参考感知的评分标准，用于评估开放式回答。一种互补的模型衍生难负例挖掘（Model-Derived Hard-Negative Mining, MDHNM）策略将模型推理过程中观察到的合理错误转化为 MCQ 干扰项，以实现更低成本的评估。在评估的异构模型池中，MCQ 准确率与 AIVC-Judge 分数呈正相关，为开放式回答评估提供了互补的性能视角。代码和数据演示见 https://anonymous.4open.science/r/OmniVCBench。

## Abstract
Artificial Intelligence Virtual Cells (AIVCs) are envisioned as scientific agents that simulate cellular responses, explain underlying mechanisms, and support hypothesis-driven discovery. Existing AIVC benchmarks, however, operate primarily at the simulation layer, motivating complementary evaluation of how models interpret experimental evidence and formulate biological hypotheses. We introduce OmniVCBench, a figure-centric, source-traceable benchmark for the interpretation component of an AIVC. It contains 6,077 curated single- and multi-subfigure question--answer pairs derived from figures and experimental contexts in the scientific literature. Guided by Bloom's taxonomy, we instantiate interpretation-layer counterparts of the AIVC Predict--Explain--Discover agenda through three scientific reasoning tasks. We further introduce AIVC-Judge, a task-conditioned MLLM-as-a-judge framework with category-specific, reference-aware rubrics for evaluating open-ended responses. A complementary Model-Derived Hard-Negative Mining (MDHNM) strategy converts plausible errors observed during model inference into MCQ distractors for lower-cost evaluation. Within the evaluated heterogeneous model pool, MCQ accuracy correlates positively with AIVC-Judge scores, providing a complementary view of performance alongside open-response evaluation. Code and data demo are available at https://anonymous.4open.science/r/OmniVCBench.

- **核心问题**：多模态大模型（MLLM）在 AIVC 中应扮演什么角色？如何评估其基于实验图表证据进行科学推理的能力？
- **整体含义**：论文提出 **OmniVCBench**，一个以图表为中心、来源可追溯的基准，专门评估 AIVC 的“解释组件”。它把 AIVC 的 **Predict–Explain–Discover（P-E-D）** 议程映射到解释层，形成 L1 证据条件推断、L2 机制解释、L3 基于证据的假设提出三项任务，并配套开放式评分与选择题评估。

## 2. 方法论

### 2.1 核心思想

- 以科学文献中的**图表 + 实验上下文**为证据来源，构造单一/多子图问答对。
- 同时提供**开放式回答**与**六选一 MCQ**两条评估轨道，覆盖相同题目。
- 用 **AIVC-Judge** 对开放式回答做参考感知、类别特定的评分；用 **MDHNM** 把模型推理错误转化为有区分度的干扰项。
- 构建辅助语料 **OmniVCTrain** 用于 SFT 与 RAG 适配。

### 2.2 任务形式化

- 源记录 \(u=(t,F,C)\)：标题、图像-标题集合、上下文。
- 构造流水线 \(G(u)\to\{z_i\}\)，其中 \(z_i=(I_i,q_i,a_i,\ell_i)\)，\(I_i\) 为图像子集，\(q_i\) 为新生成问题，\(a_i\) 为参考答案，\(\ell_i\in\{1,2,3\}\) 为解释层级。
- 推理时模型只接收图像与问题：
  - 开放式：\(\hat{r}_i=F_\theta(I_i,q_i)\)
  - MCQ：\(\hat{k}_i=F_\theta(I_i,q_i,O_i)\)，\(O_i\) 为六选项集合。

### 2.3 三层任务定义

- **L1 证据条件推断**：从显示的证据中推导数值、方向、关系或结果；对应 P-E-D 的 Predict 类比，Bloom 层级 2–4。
- **L2 机制解释**：用生物学过程解释观察结果；对应 Explain，Bloom 4。
- **L3 基于证据的假设提出**：提出与证据一致、可检验的假设；对应 Discover 前置，Bloom 5（Evaluate），而非无约束的 Create。

### 2.4 数据构造与质量控制

- 从 OmniScience 语料检索与 AIVC 相关的记录，覆盖虚拟细胞、扰动响应、单细胞/空间组学、多组学、机制通路、疾病细胞生物学六大主题。
- 使用 Kimi-K2.6 与 Qwen-VL-MAX 两个生成模型等概率生成候选 QA，以降低单一模型风格印记。
- 经过 schema、证据、答案特异性、视觉 grounding 检查后，由**三名细胞生物学博士标注者独立盲审**，仅保留**一致通过**的条目。
- 最终从 7,923 个候选中保留 **6,077 个条目**（保留率 76.70%），来自 2,625 个源记录、1,080 篇论文；Fleiss’ κ = 0.8560。

### 2.5 MDHNM（模型衍生难负例挖掘）

- 从异构模型池对同一图像-问题做 12 次 rollout，保留 AIVC-Judge 总体分 ≤ 2 的低分回答，形成错误池 \(E_i\)。
- 生成模型将错误候选改写成与参考答案在句法、细节、长度上一致的干扰项，同时保留错误。
- 筛选准则：科学错误性、合理性、相关性/grounding、多样性、唯一性、风格一致性；长度比约束 \(0.95\le|d|/|a_i|\le1.25\)。
- 最终 \(|D_i|=5\)，与参考答案随机排序为 A–F 六选项。

### 2.6 AIVC-Judge

- 任务条件化的 MLLM-as-a-judge，输入问题、候选回答、原始图像、caption、上下文、参考答案。
- 将回答分解为原子主张，逐条与证据核对，输出维度分、总体分（1–5）和证据 trace。
- 层级维度：
  - L1：correctness；evidence support
  - L2：faithfulness；causal completeness；mechanistic granularity；evidence consistency
  - L3：judgment correctness；argumentation quality；evidence weighing
- 生产 judge 为 DeepSeek-V4-Flash-Vision-Exp，温度 0，匿名候选身份。
- 人类验证：在分层 300 项样本上，人类总体分与 judge 的 Spearman ρ = 0.877（884 个配对回答）。

### 2.7 OmniVCTrain

- 548,450 条粗粒度图像-问题-答案示例，用于 SFT 与 RAG。
- 排除与基准源论文标题/DOI 匹配的训练样本；发布级审计未确认重叠。

  - L3 提案导向 rubric 敏感性 pilot（24 项冻结样本，Human 4/5 重新评分）。

## 4. 资源与算力

- 论文**未明确报告 GPU 型号、数量或训练时长**。
- 仅提及：
  - LoRA SFT 使用 LLaMA-Factory，Qwen3-VL-8B，rank 16/32，2 epochs，序列截断 2,048，bf16，学习率 \(10^{-4}\)，cosine schedule，warmup 0.03，seed 42，冻结视觉塔与 projector。
  - 训练数据规模：全量 548,016 条或 100,000 条子集；有效 batch size 64 或 56。
  - 使用 PEFT 0.18.1、Transformers 5.8.0、Torch 2.8.0。
  - 开源模型在本地 HuggingFace 运行；专有模型通过 OpenRouter/官方 API。
- 作者在“不足与局限”中明确表示**计算资源有限**，未能探索更大骨干、更长训练、偏好优化或 agentic 训练。

## 5. 实验数量与充分性

- **主实验**：15 个模型 MCQ + 11 个模型开放式评分，覆盖 L1–L3 三层。
- **适配实验**：2 种 SFT 配置 + 多模态 RAG，以及跨 3 个基座模型的 RAG 对比。
- **消融实验**：
  - MDHNM vs. 直接生成干扰项（3 个生成器，分层 300 项）。
  - 同证据直接/挖掘干扰项对比（2 个 solver，5 个干扰项臂）。
  - RAG 检索信号消融（联合/图像/文本）。
  - 无图像捷径测试（5 个模型）。
  - L3 rubric 敏感性 pilot（24 项，2 名新标注者，3 种条件）。
- **人类验证**：3 名标注者做 MCQ 与开放式评分；另有 2 名标注者做 L3 pilot。
- **可执行 pilot**：4 个真实生物输出场景，36 个案例，108 次模型调用。
- **统计**：源论文聚类 bootstrap、Holm 校正、McNemar 检验、Spearman/Pearson/QWK 等。
- **充分性评价**：
  - 实验数量较多，覆盖主评估、消融、人类验证与可执行循环，**整体较充分**。
  - 但适配实验仅限单一 8B 骨干；开源模型规模集中在 2B–8B；pilot 样本小且为一步回放；L3 rubric 敏感性仅 24 项。因此结论的**外部效度有限**，部分对比混合了模型容量、算力与推理配置。

## 6. 主要结论与发现

- **最强专有模型也未饱和**：GPT-5.6-sol 达到 55.1% MCQ 准确率与 3.28/5 AIVC-Judge 分；L3 开放式仅 2.76/5。
- **MCQ 与开放式评分高度相关但不等价**：11 个共享模型上 Spearman ρ = 0.964；但四个专有模型内部 Pearson r 仅 0.208，存在排名反转。
- **视觉证据贡献显著但模型依赖**：GPT-5.6-sol 无图像时准确率从 57.3% 降至 34.7%；部分开源模型无下降。
- **适配增益有限且配置依赖**：rank-32 SFT 提升 1.97 个百分点，多模态 RAG 提升 1.60 个百分点；最强适配 Qwen 仍仅 35.79%，与专有模型差距大。
- **L3 是最弱环节**：提案导向 rubric 下同一批回答得分可升至 4.75–4.83，说明历史 L3 总分对 rubric 敏感，并非纯假设能力度量。
- **证据获取 pilot 显示局部修正能力**：三个数值 pilot 中获取选定测量后共 9 次错误→正确、0 次正确→错误；自审无提升甚至退化；真实显微镜分类无增益。
- **配对评估揭示不同错误模式**：MCQ 选对可能伴随开放式解释方向错误，反之亦然；L3 中可存在可辩护假设与错误选项并存。

## 7. 优点

- **定位清晰**：明确补足 AIVC 解释层评估，与模拟层基准形成互补。
- **来源可追溯**：每个答案关联源论文图表与实验上下文，便于审查。
- **配对双轨评估**：同一题目同时提供开放式与 MCQ，兼顾生成质量与低成本确定性评估。
- **AIVC-Judge 设计细致**：任务条件化、层级维度、claim-level 证据 trace、参考感知评分。
- **MDHNM 有创新性**：用真实模型错误构造干扰项，比直接生成更难、更具区分度。
- **质量控制严格**：三标注者一致通过、盲审、Fleiss’ κ 报告、人类验证 judge。
- **可执行 pilot**：在真实生物输出上测试证据获取与预测修正，连接基准与闭环工作流。
- **开放资源**：承诺发布 judge 实现、rubric、300 项 demo 及完整数据。

## 8. 不足与局限

- **源分布狭窄且陈旧**：全部来自 Nature Communications 2011–2017，小鼠/人类、显微镜/免疫印迹主导；未覆盖 2018 年后开放获取期刊、失败实验、原始仪器读数。
- **文本捷径风险**：无图像控制显示 GPT-5.6-sol 仍达 34.7%，问题文本、选项、领域先验和潜在预训练记忆均贡献显著；预训练暴露未量化。
- **L3 评分效度有限**：历史 L3 rubric 评估的是“批判性论证”而非“提案质量”，与 L1/L2 总分不可直接比较；提案导向 rubric 仅在小样本 pilot 中验证。
- **人类验证输入不完全一致**：人类评分未提供原始图像，judge 有图像，因此验证的是共享文本证据与 rubric 应用，而非 judge 的视觉阅读。
- **模型覆盖与公平性**：开源模型仅 2B–8B，与专有模型对比混合了容量、算力和推理配置，不能简单归因于开放/封闭身份。
- **适配研究有限**：仅 LoRA SFT 与 RAG，单一 8B 骨干，未探索更大模型、偏好优化、agentic 训练。
- **pilot 范围小**：36 个案例、108 次调用，为一步回放，未重训模拟器，未验证完整发现闭环；药物组合 pilot 饱和，显微镜 pilot 无增益。
- **MCQ 与开放式相关性受组间分离影响**：池化相关高，但专有模型内部弱，跨轨相关是内部一致性度量（judge 同时参与干扰项过滤与开放式评分）。
- **干扰项难度来源复杂**：同证据直接 vs. 挖掘差异不显著，最终难度由完整发布配置（迭代改写、筛选、审计）共同驱动。
