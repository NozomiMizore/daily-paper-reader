## 摘要
在多种细胞类型中进行的单细胞CRISPR筛选被用于比较不同细胞类型对扰动的响应、训练可在细胞类型之间迁移效应的模型，以及评估此类模型。这些用途都假设携带向导RNA的细胞其靶基因已被敲低。然而，细胞在测序前会生长数天：当必需基因被敲低时，被敲低的细胞会耗竭或停止分裂，而逃逸敲低的细胞继续生长，因此所测响应——对携带该向导的所有细胞取平均——被稀释。我们将某一扰动的逃逸比例定义为在其被测细胞中靶基因未被有效敲低的细胞所占比例，并利用每个细胞中靶基因的计数，通过两组混合模型进行估计；该模型在模拟混合样本中能恢复已知比例。在大多数细胞类型中，逃逸比例随基因必需性的增加而升高；对同一批细胞进行较晚期的筛选时该比例更高；在人胚胎干细胞（hESCs）中，它达到被测细胞的一半左右。它可预测每种响应被稀释的程度：响应大小降至被敲低细胞响应大小的 (1 - e)^2。由于逃逸比例因细胞类型而异，它改变了上述三种用途：除非敲低导致 hESCs 耗竭，否则 hESCs 的响应与 K562 细胞相似；简单迁移模型学到的系数会因其预测细胞类型的稀释而降低；在所有细胞上评分的基准会奖励向“无变化”收缩的预测，部分原因是该真实值本身已被稀释。在细胞改为停止分裂的情况下，响应中还包含细胞周期各阶段之间的表达差异。响应大小应在被敲低细胞上进行比较，或按逃逸比例进行校正。

## Abstract
Single-cell CRISPR screens run in many cell types are used to compare how cell types respond to perturbation, to train models that transfer effects between them and to score such models. These uses assume that cells carrying a guide RNA had their target knocked down. Yet cells grow for days before sequencing: when an essential gene is knocked down, knocked-down cells are depleted or stop dividing while cells that escaped knockdown keep growing, and the measured response, an average over all cells carrying the guide, is diluted. We define the escape fraction of a perturbation as the share of its measured cells whose target was not effectively knocked down, and estimate it from each cell's counts of the targeted gene with a two-group mixture that recovers known fractions in simulated mixtures. In most cell types the escape fraction rises with how essential the gene is, it is higher in a later screen of the same cells, and it reaches about half of the measured cells in human embryonic stem cells (hESCs). It predicts how much each response is diluted: the response size falls to (1 - e)^2 of that of the knocked-down cells. Because the escape fraction differs between cell types, it changes all three uses: hESCs respond like K562 cells unless knockdown depletes them, the coefficient a simple transfer model learns is lowered by the dilution of the cell type it predicts, and a benchmark scored on all cells rewards predictions shrunk towards no change, partly because that ground truth is itself diluted. Where cells stop dividing instead, the response also contains expression differences between cell-cycle stages. Response sizes should be compared on knocked-down cells or corrected for the escape fraction.

## 1. 核心问题与整体含义

- **背景**：单细胞 CRISPR 筛选（如 Perturb-seq、CRISPRi）向每个细胞递送一条 guide RNA，敲低一个基因，然后测序该细胞的转录组。此类筛选已覆盖癌细胞系、原代细胞、多能干细胞、分化细胞等。
- **三种典型用途**：
  - 生物学解释：比较不同细胞类型对扰动的响应强弱，例如认为 hESC 比 K562 “更抗扰动”。
  - 训练跨细胞类型迁移模型：学习响应大小如何随细胞类型变化。
  - 评估模型：基准用实测响应作为 ground truth，并据此设定模型可达上限。
- **共同隐含假设**：携带 guide 的细胞中，目标基因已被有效敲低。
- **现实问题**：细胞在测序前会生长数天至两周。必需基因被敲低后，真正被敲低的细胞会耗竭或停止分裂，而逃逸敲低的细胞继续增殖。测得的响应是所有携带该 guide 细胞的平均，因此被逃逸细胞稀释。
- **逃逸细胞的来源**：guide 作用弱或无效、guide 分配错误（多 guide、环境 guide RNA、guide reads 少）、以及部分敲低细胞。
- **研究空白**：已有工具（Mixscape、ContrastiveVI+ 等）在单数据集内识别或建模“未扰动细胞”，但尚未系统测量：
  - 逃逸比例是否在不同细胞类型间不同；
  - 它究竟稀释多少响应；
  - 它是否改变上述三种用途的结论。
- **整体含义**：逃逸比例不是恒定的 nuisance 参数，而是随基因必需性、细胞类型和收获时间系统变化，因而会扭曲跨细胞类型比较和模型评估。

## 2. 方法论

### 2.1 核心思想

- 定义**逃逸比例 \(e\)**：某一扰动的被测细胞中，目标基因未被有效敲低的细胞所占比例。
- 仅使用**目标基因自身的计数**估计 \(e\)，不使用响应基因，从而避免“用响应定义逃逸、再用逃逸解释响应”的循环。
- 将每个细胞的目标基因计数建模为两组混合：
  - 一组为敲低细胞，表达降至敲低水平；
  - 一组为逃逸细胞，表达处于对照水平。

### 2.2 混合模型细节

- 对每个细胞 \(i\)，其目标基因的对照期望计数为：
  - \(\mu_i =\) 对照细胞中该基因的表达率 \(\times\) 该细胞的总文库大小。
- 两个竞争模型：
  - **均匀敲低模型**：\(c_i \sim \mathrm{NB}(r\mu_i, k)\)，即所有细胞共享一个敲低水平 \(r\)。
  - **两组混合模型**：\((1-e)\,\mathrm{NB}(r_{kd}\mu_i,k) + e\,\mathrm{NB}(\mu_i,k)\)，其中逃逸组位于对照水平。
