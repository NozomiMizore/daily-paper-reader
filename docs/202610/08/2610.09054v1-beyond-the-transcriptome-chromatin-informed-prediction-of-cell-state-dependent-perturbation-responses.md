## 摘要
预测遗传扰动引起的转录响应是理解基因功能的核心。现有预测器主要依赖转录组测量，尽管染色质可及性可提供关于扰动所作用细胞环境的补充信息。利用这些信息需要将染色质背景与特定扰动联系起来，并考虑独立采样的对照与扰动群体之间的基线差异。我们提出 ChromaPert，一个基于染色质信息的框架，用于预测状态依赖性扰动响应。ChromaPert 将分子和 DNA 信息引导的位点先验与配对的对照 RNA--ATAC 特征相结合，以联合表示靶标身份和实测细胞环境。其染色质引导响应路由器（Chromatin-Guided Response Router, CGRR）构建由对照衍生的表达偏移组成的源库，并利用扰动/位点或对照-ATAC 相似性检索相关源。这些偏移可解释基线差异，而条件传输流学习其余响应。在 K562 CAT-ATAC 和 Perturb-Multiome 上的三种未见靶标和留出状态设置中，ChromaPert 在所评估方法中取得了最高的全基因响应相关性。当将已知扰动迁移到留出状态时，相对于各自最强基线，它在所有基因上提升了 23.2% 的相关性，在二十个响应最强基因上提升了 46.2%。正确的 RNA--ATAC 配对相比打乱配对改善了染色质相关响应斜率的恢复，而跨状态预测保留了对同一扰动的状态特异性响应。

## Abstract
Predicting transcriptional responses to genetic perturbations is central to understanding gene function. Existing predictors primarily rely on transcriptomic measurements, although chromatin accessibility provides complementary information about the cellular context in which perturbations act. Using this information requires linking chromatin context to specific perturbations and accounting for baseline differences between independently sampled control and perturbed populations. We propose ChromaPert, a chromatin-informed framework for predicting state-dependent perturbation responses. ChromaPert combines molecular and DNA-informed locus priors with paired control RNA--ATAC features to jointly represent target identity and measured cellular context. Its Chromatin-Guided Response Router (CGRR) builds a source bank of control-derived expression offsets and retrieves relevant sources using perturbation/locus or control-ATAC similarity. These offsets account for baseline differences, while conditional transport flow learns the remaining response. Across three unseen-target and held-out-state settings on K562 CAT-ATAC and Perturb-Multiome, ChromaPert achieves the highest all-gene response correlation among evaluated methods. When transferring known perturbations to held-out states, it improves correlation by 23.2% across all genes and 46.2% for the twenty most responsive genes over the strongest respective baselines. Correct RNA--ATAC pairing improves recovery of chromatin-associated response slopes over shuffled pairing, while cross-state predictions retain state-specific responses to the same perturbation.

## 1. 核心问题与整体含义

- **研究动机**：预测遗传扰动引起的转录响应是功能基因组学与基因功能解析的核心任务。单细胞 CRISPR 筛选（如 Perturb-seq）覆盖不完整，因此需要 in silico 预测未见扰动与细胞背景下的响应。
- **现有局限**：主流预测器（GEARS、CPA、CellFlow、scGPT 等）仅用 scRNA-seq 转录组刻画细胞状态，忽略了**染色质可及性**所编码的调控上下文。染色质可及性一方面影响转录因子招募与下游转录（如糖皮质激素受体结合），另一方面可区分 RNA 相似但调控状态不同的细胞背景。
- **两大挑战**：
  - **(i) 背景—扰动关联**：对照 RNA–ATAC 描述未扰动细胞，而预测目标是特定扰动的表达变化，模型需学习二者如何共同塑造响应。
  - **(ii) 基线差异**：单细胞分析具破坏性，对照与扰动为独立采样（非纵向配对），观测差异中混杂了预先存在的基线偏移与真实扰动响应，需加以区分而非误学为扰动效应。

## 2. 方法论

- **核心思想**：将扰动响应分解为「对照衍生的基线偏移」+「条件传输流学习的剩余位移」，并以染色质上下文条件化。
- **组件一：染色质信息扰动条件化**
  - 分子先验：ESM-2 蛋白嵌入（64 维）+ CLM-X RNA-token 嵌入（64 维）→ `up ∈ R128`。
  - DNA 位点先验：TSS 中心序列特征（96 维）+ 调控投影（cCRE、JASPAR、guide 描述符，128 维）→ `ℓp ∈ R224`；`xp = [up‖ℓp] ∈ R352`。
  - 对照上下文：配对对照 RNA（96 维）+ ATAC（64 维，control-only TF-IDF/LSI）→ `hs ∈ R160`。
  - 条件拼接：池化分支 `cpool = [xp‖ℓp] ∈ R576`；状态感知分支 `cstate = [xp‖ℓp‖hs] ∈ R736`。所有块用训练折标准化，缺失先验零填充。
- **组件二：染色质引导响应路由器（CGRR）**
  - 源库：对照 RNA 偏移 `Bs = bs − b̄tr ∈ RG`（不含观测扰动效应）。
  - Target-LOO 按 target/locus 相似度软路由（温度 τfeat=0.20）；Cross-State 按对照 ATAC 与训练原型余弦相似度路由（τATAC=0.15）。
  - 基线分解：`dsource = Σ mq(s) Bs`，源调整响应 `∆̃i = ∆i − dsource_i`，显式剥离组成加权的对照偏移。
- **组件三：条件传输流与响应重建**
  - 条件流匹配（CFM）：以训练对照均值作 PCA 锚点 `z0 = EPCA(b̄tr)`，端点 `z1 = EPCA(b̄tr + y)`，线性路径 `zt = (1−t)z0 + t z1`，最小化速度场平方误差；Euler 求解，默认 NFE=8，PCA 仿射偏移在位移中抵消。

  - 状态中心分支：以 `ri,s = μpert_i,s − bs` 为流目标，聚合得 `statebase`。
  - 重建：Target-LOO 经训练折可靠性门控输出 `∆gate`；Cross-State 经 ATAC 权重迁移状态中心响应。最终 `bμpert = bq + b∆`，群体读出按提供的状态比例聚合。

- 在三种设置中，ChromaPert 均取得**最高的全基因响应相关性**（Pearson ∆）与判别余弦。

## 7. 优点

- **问题切入新颖**：首次系统性地将染色质可及性作为扰动响应预测的上下文信息，并明确区分「基线偏移」与「扰动响应」。
- **方法设计结构化**：CGRR 源库 + 条件传输流的分解，优雅处理非配对采样下的基线混杂问题，避免将对照差异误学为扰动效应。
- **多源先验融合**：蛋白、RNA-token、TSS 序列、cCRE/JASPAR 调控注释与配对 RNA–ATAC 上下文互补，且各块维度、投影与训练折约束清晰。

## 8. 不足与局限

- **输入依赖强**：需配对的 scRNA-seq 与 scATAC-seq 对照及兼容的 promoter 可及性映射，缺乏配对多组学对照时无法直接应用。
- **数据覆盖有限**：仅两个数据集（K562 细胞系 + 造血分化轨迹），靶标 18–19 个，跨组织、跨物种、跨扰动类型的泛化性未验证。
- **读出限制**：仅预测扰动后表达，群体读出依赖外部提供的状态比例，不估计扰动诱导的细胞类型丰度变化。

- **因果性未建立**：ATAC 配对分析明确声明不建立因果关系；靶标特异性通路恢复仍属探索性（标签置换支持有限）。
- **偏差风险**：预测可能继承源数据、细胞状态注释与外部参考资源的技术/生物偏差，需独立实验验证，仅限计算研究与假设生成。
