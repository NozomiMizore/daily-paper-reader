## 摘要
药物反应预测（DRP）模型是药物基因组学中的一个活跃研究领域，在加速识别有效抗癌药物方面具有越来越大的潜力。然而，其预测性能常常受到数据集规模有限以及癌症和化学空间覆盖不足的限制。此外，不一致的基准测试实践阻碍了跨模型的可靠比较。标准化框架，如预测肿瘤学模型评估的创新方法和新数据（IMPROVE）项目，提供了统一的数据模式和评估协议，以进行一致的基准测试，但提高模型的泛化能力需要更大、更多样化的训练数据。在这项工作中，我们通过大规模整合药物基因组学数据（主要来自PharmacoDB，以及其他较小的数据源）大幅扩展了IMPROVE基准。扩展后的资源包括数百万个药物反应测量、更广泛的多组学覆盖，以及化学多样性的显著增加，新增了超过50,000种化合物。为了评估新数据集与原始IMPROVE基准数据集相比的影响，我们使用这两个数据集训练DRP模型，并使用共同的测试集和多种评估策略（包括药物盲、癌症盲和不相交数据划分）评估其预测性能。虽然癌症盲性能与原始基准相当，但在扩展数据集上训练的模型在药物盲和不相交设置中表现出持续改进，表明对未见化合物的泛化能力增强。这些结果使扩展数据集成为一个社区资源，为开发旨在帮助发现新型抗癌药物的DRP模型提供了更丰富的基础。

## Abstract
Drug response prediction (DRP) models are an active area of research in pharmacogenomics, with growing potential to accelerate the identification of effective anticancer drugs. However, their predictive performance is often constrained by limited dataset scale and insufficient coverages of cancer and chemical spaces. In addition, inconsistent benchmarking practices hinder reliable comparison across models. Standardized frameworks, such as the Innovative Methodologies and New Data for Predictive Oncology Model Evaluation (IMPROVE) project, provide unified data schemas and evaluation protocols for consistent benchmarking, but improving model generalizability requires larger and more diverse training data. In this work, we substantially expand the IMPROVE benchmark through large-scale integration of pharmacogenomic data, primarily from PharmacoDB, together with additional smaller data sources. The expanded resource includes millions of drug response measurements, broader multi-omics coverage, and a major increase in chemical diversity, adding more than 50,000 compounds. To evaluate the impact of the new dataset compared to the original IMPROVE benchmark dataset, we trained DRP models using the two datasets and assess their prediction performance using a common test set and several evaluation strategies, including drug-blind, cancer-blind, and disjoint data splits. While cancer-blind performance remained comparable to the original benchmark, models trained on the expanded dataset showed consistent improvements in drug-blind and disjoint settings, indicating enhanced generalization to previously unseen compounds. These results position the expanded dataset as a community resource that provides a richer foundation for developing DRP models intended to aid in the discovery of novel anticancer drugs.

- **整体含义**：这项工作不仅仅是数据量的叠加，而是通过严格的标准化与统一的数据模式（schema），将海量异质数据转化为可供现代机器学习模型直接使用的社区级资源，为开发更具泛化性的DRP模型、加速抗癌药物发现奠定数据基础。

## 2. 论文提出的方法论

### 2.1 核心思想
将多个异质的药物筛选研究数据整合为统一、标准化的“AI-ready”格式，在保持IMPROVE框架的基准一致性前提下，大幅扩展数据规模与化学覆盖，并在相同测试集上对比新旧数据集对模型性能的影响。

### 2.2 数据整合与标准化流程

- **数据来源**：主要从PharmacoDB获取，涵盖11个数据集，包括CCLE、CTRPv2、GDSCv1/v2、gCSI、NCI-60、PRISM、FIMM以及4个患者来源类器官（PDO）研究。
- **统一标识符**：化合物使用Canonical SMILES统一；细胞系映射至Cellosaurus ID；基因标识符（Ensembl/Entrez/Symbol）通过NCBI映射表统一。
- **药物反应数据**：
  - 对原始细胞活力测量值做截断处理（上限200% viability），保留极端实验数据。
  - 使用四参数逻辑斯蒂（4PL）剂量-反应模型拟合：
    ```
    f(x) = E∞ + (E0 - E∞) / (1 + 10^((x - EC50)·HS))
    ```
    其中 x 为 log10 摩尔浓度，E0/E∞ 为零剂量和无穷大剂量响应，EC50 为半最大响应浓度，HS 为 Hill 斜率。
  - **严格回归（strict regime）**：E0 = 1，E∞ ∈ [0,1]，HS ∈ [-5,5]，禁止曲线反转。
  - **灵活回归（flexible regime）**：允许曲线反转（HS > 0），放宽E0和E∞界限，适配少数响应随剂量上升的反常实验；以 R² 为标准，仅当反转拟合改善 R² 时才保留反向曲线。
  - 计算两种方式下的AUC，并对AUC值封顶至1.0。
- **化学特征**：
  - 使用RDKit清洗SMILES、去除盐/反离子、生成规范SMILES并归并互变异构体。
  - 两种特征模态：Mordred计算的物理化学描述符（3D描述符关闭）、ECFP4指纹（半径2，512位）。
- **多组学数据**（来源：DepMap 22Q2 + PharmacoDB补充）：
  - 涵盖6种模态：基因表达、拷贝数变异（CNV）、体细胞突变、DNA甲基化（RRBS-TSS）、蛋白质表达（RPPA）、miRNA表达。
  - 基因表达采用 log2(TPM+1) 表示，跨源数据合并后进行分位数归一化。
  - CNV 提供连续值（log2 ratio + 1）和五态离散化版本（-2/ -1/0/1/2）。
  - 突变数据提供基因级计数矩阵与逐突变长表格双重格式。

## 3. 实验设计

### 3.1 数据集与基准
- **原始基准**：IMPROVE 原始基准数据集（含 CCLE、GDSC、gCSI、CTRPv2）。
- **扩展数据集**：上述来源 + NCI60、PRISM、FIMM及PDO研究，总计约 **545万药物-反应实验**（原始数据约 65万），覆盖 **53,949种化合物**（原始约 700+），**1,362个癌症样本**。
- **多组学覆盖**：基因表达 1,907 个细胞系（1,354 有响应数据），CNV 1,764，突变 1,769，RPPA 894，miRNA 946，甲基化 839。

### 3.2 评估协议
- **10折交叉验证**，每一折从 GDSC、CCLE、CTRPv2（新旧基准共同含有的源）中划分，保证新旧数据集使用**完全相同的测试集**。
- 评价标准设为四种数据划分下 R² 与 Pearson 相关系数：
  - **Mixed（混合）**：药物和细胞系均见过，但配对未见。
  - **Drug-blind（药物盲）**：药物未见，细胞系见过。
  - **Cancer-blind（癌症盲）**：细胞系未见，药物见过。
  - **Disjoint（不相交）**：药物和细胞系均未见（最严格）。
- 为严格防止信息泄漏，凡涉及held-out药物或细胞系的实验（无论来自哪个数据源）一律排除出训练集。

### 3.3 对比模型
- **UNO**：基于全连接子网络分别编码药物描述符和基因表达，并在层间加入残差连接。
- **GraphDRP**：基于图卷积网络，将药物编码为分子图，细胞系使用基因表达特征，学习图级结构表示。

## 6. 主要结论与发现

- **药物盲与不相交设置显著提升**：扩展数据集训练下，UNO 的药物盲 R² 从 0.03 → 0.22（PCC 0.39 → 0.51），GraphDRP 从 -0.11 → 0.12（PCC 0.21 → 0.45）；不相交设置中 UNO R² 从 -0.10 → 0.20，GraphDRP 从 -0.26 → 0.08。这说明更大化学空间显著提升了模型对**未见化合物**的泛化能力，这一增益在两种架构中一致出现，与该数据集本身的特性相关。
- **癌症盲与混合设置基本持平或小幅下降**：cancer-blind R² 从约 0.60 → 0.57-0.58；mixed R² 从 0.71-0.75 → 0.66-0.67。
- **性能权衡的解释**：扩展数据集中 NCI60 占了绝对多数（约427万/545万实验），其在数据类型、实验协议上与其他源（GDSCv2、CCLE、CTRPv2）存在差异，导致训练分布偏移，造成了 mixed 和癌症盲上的轻微下降。
- **总体评价**：大规模+化学多样性是提升DRP泛化能力的关键因素，扩展数据集作为社区资源具有明确价值，但分布失衡的副作用需要后续研究平衡处理。

## 7. 优点

1. **大规模真实数据整合**：首次将超过500万条药物-反应测量和5万+化合物统一为标准化、模型可直接读取的格式，规模远超现有基准。
2. **严格标准化与质量控制**：从SMILES清洗、盐去除、互变异构体归一化，到四种参数约束的剂量-反应拟合方案，工程设计细致，极大降低了跨源数据的异质性噪声。
3. **多层次泛化评估框架**：同时采用混合、药物盲、癌症盲、不相交四种划分，系统刻画模型在不同泛化维度上的表现，兼具深度与广度。
4. **双模型交叉验证结论稳健性**：UNO 和 GraphDRP 基于完全不同的药物表示（描述符 vs. 分子图），结果趋势一致，增强了对结论的信心。
5. **严格防止信息泄漏**：所有涉及held-out药物或细胞系的实验都被排除出训练集，测试集绝对纯净，评估公正性高。
6. **多组学资源丰富**：六种分子模态数据同时发布，为未来多组学融合和基础模型/预训练研究提供了良好基础。

## 8. 不足与局限

### 8.1 实验覆盖与偏差风险
- **数据分布严重失衡**：NCI60 贡献了约 78% 的实验数据（427万/545万），但其测定的细胞系仅有85种、采用不同实验测定方案（与共享测试集来源不同），可能使模型偏向于NCI60特有的实验信号，削弱在GDSC/CCLE/CTRPv2上的分布内性能。
- **化合物重叠有限**：NCI60 中5万+化合物与GDSC/CTRPv2等研究使用的化合物重叠极少，这一点未在文中有充分分析；化学空间的大幅扩展对药物盲任务的提升可能部分来自“数据量”而非“多样性”，两者贡献无法分离。
- **批量效应未充分处理**：尽管做了归一化等处理，但不同研究间的系统性批次差异（batch effects）仍存在，是否对性能产生了影响未能定量评估。

### 8.2 模型评估局限
- **未使用多组学输入**：论文只使用了基因表达一种细胞系特征，RPPA、甲基化、miRNA、突变、CNV 等丰富模态未在实验中验证价值，宣称“多组学扩展”的实际建模效果尚未得到验证。
- **未做消融实验**：无法区分数据量增加 vs. 化学多样性增加 vs. 数据源结构差异各自对性能的贡献。
- **未调参**：模型使用默认超参数，batch size 改变后是否最优未验证，扩展数据集上的模型容量和训练策略可能未达最优。

### 8.3 计算与应用限制
- **算力门槛高**：数百万量级的训练数据要求多GPU集群，单卡/普通实验室难以复现或独立使用，限制了社区的参与度。
- **训练时长与资源细节缺失**：未报告具体的GPU型号、训练时长、能源消耗等，不利于其他团队预估复现成本。
- **应用场景局限**：尽管扩展了PDO数据，但癌症类型、组织来源的多样性仍有限（以常见细胞系面板为主），对罕见癌症、体内微环境、联合用药等临床场景的迁移能力尚未验证。

### 8.4 其他
- **NCI60数据规模远超其余数据集**，导致“扩大数据”与“数据不平衡”两个因素交织，论文对这种 trade-off 只做了定性解释，缺少定量证据（如去除NCI60后重新评估的对照实验）。
- 部分 fold 结果方差较大（如 GraphDRP 扩展数据集的 drug-blind R² 标准差达 0.28），个别划分下甚至出现负向效果，说明提升并非在所有数据划分下都稳定。
