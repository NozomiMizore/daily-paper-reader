## 摘要
受体占用模型量化癌症信号传导的抑制，通常将靶点占用作为下游活性的替代指标。尽管这种简化产生了低维模型，但它无法表示由细胞内网络产生的延迟通路关闭、瞬时耐药性或非单调活力响应。我们构建了一个快慢框架，区分药物-靶点占用与下游信号活性。快变量X表示占用，活性变量A表示促生存信号，慢变量B表示自适应反馈，包括磷酸酶诱导、应激适应或信号重连。快速占用松弛允许准稳态降阶，而弱反馈保证全局收敛到唯一平衡。更强的反馈可能使冻结的活性子系统接近鞍结折叠，产生一种“幽灵”状态，其中轨迹在已消失的高活性平衡残余附近徘徊。我们确定了慢自适应通过何时保留平方根反比的幽灵定律，或在横向穿越时产生动态延迟尺度O(ε^{-1/3})。将活性与活力耦合将这些延迟转化为剂量-反应曲线中的平台期，而自适应滞后可能在没有临时强制的情况下产生早期过冲。对时间分辨活力数据的概念验证拟合再现了跨测量浓度和观测时间的模式，并揭示了实际可辨识性的局限性。该框架还预测了表观效力的暴露时间依赖性变化，包括IC50(t)，因为活力是对信号活性随时间的积分，而不仅仅是受体占用。

## Abstract
Receptor occupancy models quantify inhibition of cancer signalling, often treating target occupancy as a proxy for downstream activity. Although this simplification yields low-dimensional models, it cannot represent delayed pathway shutdown, transient resistance, or non-monotone viability responses generated by intracellular networks.   We formulate a fast--slow framework that distinguishes drug--target occupancy from downstream signalling activity. The fast variable $X$ represents occupancy, the activity variable $A$ represents pro-survival signalling, and the slow variable $B$ represents adaptive feedback including phosphatase induction, stress adaptation, or signalling rewiring. Rapid occupancy relaxation permits a quasi-steady reduction, while weak feedback guarantees global convergence to a unique equilibrium. Stronger feedback may bring the frozen activity subsystem near a saddle-node fold, producing a ghost regime in which trajectories linger near the remnant of a vanished high-activity equilibrium. We determine when slow adaptive passage preserves the inverse-square-root ghost law or, under transverse crossing, produces the dynamic delay scale $O(\varepsilon^{-1/3})$.   Coupling activity to viability translates these delays into shoulders in dose--response curves, while adaptive lag may generate early-time overshoot without ad hoc forcing. A proof-of-concept fit to time-resolved viability data reproduces patterns across measured concentrations and observation times and reveals practical identifiability limitations. The framework also predicts exposure-time-dependent shifts in apparent potency, including $IC_{50}(t)$, because viability integrates signalling activity over time rather than receptor occupancy alone.

### 一、核心问题与整体含义（研究动机与背景）

- **背景**：癌症信号传导的定量模型常用受体占用率（receptor occupancy）作为下游信号活性的代理指标。这种建模策略（如CXCL12/CXCR4轴竞争性激活-抑制模型）结构清晰、维度较低、参数可测量，因此被广泛使用。
- **核心问题**：受体占用与信号激活是不同层次的药理概念。占用率不能决定激活的幅度或持续时间，且激活可能在外源性配体解离后仍持续存在。传统的占用-代理模型无法表达以下现象：
  - 延迟的通路关闭（delayed pathway shutdown）；
  - 瞬时耐药性（transient resistance）；
  - 非单调的细胞活力响应（non-monotone viability responses）；
  - 靶向治疗后的适应性与信号重连（adaptive rewiring and feedback relief）。
- **整体含义**：本文建立了一个数学上清晰的桥梁，将竞争性受体占用模型与网络介导的信号动态连接起来，为上述现象提供了统一的机制性解释，并为药物效力的时间依赖性（如 IC50(t)）奠定了理论基础。

### 二、方法论（核心思想、关键技术细节、公式流程）

- **整体框架**：建立一个三层快慢系统，区分（1）受体占用层、（2）信号活性层与（3）慢适应调节层。通过理论分析来刻画不同场景下的动力学行为。
- **核心思想**：受体占用只是“输入层”，活性A与慢适应B的相互作用产生非线性动力学与幽灵现象。整体分析架构为：**快占用层→准稳态输入→冻结活性子系统的折叠几何→快慢耦合动力学→活性积分到生存活力**。
- **三层模型结构**：
  - **快变量X（占用）**：满足 Ẋ = (1/η) FX(X; C)，0 < η ≪ 1，指数快速松弛到唯一准稳态 Xqs(C)。
  - **活性变量A**：Ȧ = λ[Φ(Xqs(C), A, B) − A]，其中 Φ 是网络介导的活性映射（可用 sigmoid 原型），λ > 0。
  - **慢适应变量B**：Ḃ = ε[Ψ(A, C) − B]，0 < ε ≪ 1，表示磷酸酶诱导、应激适应或信号重连的综合效应。
- **关键技术细节**：
  - **全局收敛定理**：当 T_C = (Φ, Ψ) 在 [0,1]² 上是压缩映射时（弱反馈区），系统有唯一不动点并全局指数渐近稳定；非平凡瞬态出现在接近失去压缩性的临界点附近。
  - **准稳态降阶的验证**：通过 Gronwall 不等式证明，未降阶系统（含快占用变量 X）与降阶系统在 |Aη(t) − Ā(t)| + |Bη(t) − B̄(t)| ≤ C_T η 意义下一致逼近（误差 O(η)）。
  - **鞍-结（saddle-node）降阶与幽灵延迟**：通过标准 Taylor 展开，冻结活性方程局部化为导引方程 ȧ = μ − a²（含高阶修正项）。当 μ = −δ < 0 时无平衡，但存在幽灵区。幽灵驻留时间严格可积：
    - T_δ = 2/√δ · arctan(M/√δ) ~ π/√δ（δ↓0），即逆平方根律。
  - **折叠曲线与相图**：定义冻结活性子系统 bF(A, B, C) = F(A, B; I(C))，证明在非退化条件下折叠集合是 C¹ 一维流形（折叠曲线），其投影到 (B, C) 平面为 C¹ 曲线；μ(B, C) > 0 时有两个简单平衡点（一稳定一不稳定），μ = 0 时合并，μ < 0 时局部消失。
  - **耦合鞍-结判据**：通过定义标量平衡残差 E(A, C) = bF(A, Ψ(A, C), C)，证明耦合系统鞍-结点条件与冻结折叠条件不同，包含反馈贡献 ∂B bF · ∂A Ψ；两者仅在 ∂B bF ∂A Ψ = 0 时重合。耦合系统鞍-节点存在非退化条件（∂AA E ≠ 0、∂C E ≠ 0）且横截特征值为负时，动力学局部等价于 十 = ν − u²。
  - **慢穿越的两种延迟尺度**：
    - 当 εδ^(3/2) → 0 时，自适应漂移可忽略，逆平方根幽灵律 T ~ π/√δ 仍然有效；
    - 当横向穿越（γc > 0）时，引入交叉比 χ = εγc/δ^(3/2)，χ ≫ 1 时延迟尺度为 O(ε^(−1/3))。约化动力学为 Riccati 方程 dy/dτ = −τ − y²，其解通过 Airy 函数给出：y(τ) = −Ai′(−τ)/Ai(−τ)。第一个极点对应 Airy 函数第一个零点 z_Ai ≈ 2.338107，因此 texit − tc = z_Ai(εγc)^(−1/3) + o(ε^(−1/3))。
  - **信号活性→生存活力模型**：设 dN/dt = G(A(t; C))N，定义相对活力 V(t; C) = N(t; C)/N_ctrl(t)，则 log V(t; C) = ∫₀ᵗ [G(A(s; C)) − G(A_ctrl(s))] ds。因为生存力是活性历史的积分而非瞬时占用，所以在进行交叉验证时能直接可视化其数学结构。

  - **自适应过冲（Bump）机制**：式 (54)–(55)，随活性变化的自适应变量 B 在突然处理时无法立即达到准稳态，产生自适应滞后，可瞬时使处理组活性超过对照组活性，从而出现早期低剂量活力过冲（V(t; C) > 1）。
  - **IC50(t) 预测**：当 C ↦ V(t; C) 连续、严格递减并穿过 1/2 时，定义 V(t; IC50(t)) = 1/2。由于生存力是信号活性的积分，IC50(t) 不必为常数；幽灵区间的早期剂量-反应曲线较平，后期由于幽灵退出与适应补偿松弛，IC50(t) 向下移动。

### 六、主要结论与发现

1. **数学结构**：在弱反馈区（Φ, Ψ 为压缩）下，降阶系统具有唯一平衡且全局指数稳定；非平凡瞬态只在接近收缩性丧失时产生。
2. **准稳态降阶有效性**：在不含占用-适应反馈的情况下，快变量降阶的速度为 O(η)，误差上界由 Gronwall 论证给出，证明了慢系统的有效性。
3. **幽灵延迟的两种尺度律**：
   - 慢自适应漂移可忽略时（ε ≪ δ^(3/2)）：T ~ π/√δ（逆平方根律）；
   - 横向穿越时：T = z_Ai(εγc)^(−1/3)（Airy 函数零点决定的 ε^(−1/3) 尺度）。
4. **冻结折叠 ≠ 耦合鞍-结点**：两者区分的关键在于反馈项 ∂B bF · ∂A Ψ；耦合鞍-结点需要满足平衡残差方程 E(A, C) = 0，而冻结折叠只要求 ∂A bF = 0。
5. **肩部源于时间尺度分离**：幽灵驻留时间 T(C) 与观察时间的匹配产生剂量-反应肩部，不是静态占用-反应曲线的结果。
6. **瞬时耐药与过冲**：幽灵区造成延迟通路关闭，自适应滞后产生早期过冲。
7. **IC50(t) 非恒定**：表观效价随观察时间漂移，两个具有相同结合动力学的实验可报告不同效价——模型的核心概念优势。
8. **概念验证拟合**：参数估计结果 v∞ = 0.0673，k = 8.10×10⁻⁴，p = 1.743，τ = 20.425，R² = 0.9567，RMSE ≈ 6.75 个百分点；有效幽灵驻留时间为 T_g(1) = 20.4h、T_g(2) = 14.4h、T_g(3) = 11.8h、T_g(4) = 10.2h。有效临界浓度 Cc 不支持正值（profile 最优在边界 0），置信区间约 [0, 0.47] mM。
