## 摘要
大型语言模型能够描述机制，但其可扩展的后训练仍依赖于成本高昂、人工筛选的生物推理轨迹。在此，我们表明细胞扰动图谱可以转而成为强化学习环境，其中测得的基因响应为生物推理提供可计算的奖励。我们引入了PertMind，它结合了可信轨迹监督初始化与基因、通路和格式层面的强化信号。仅通过前向扰动-响应预测进行训练，PertMind在未见过的细胞环境中提升了响应推断能力，同时保留了通用语言能力。它还无需针对特定任务的后续训练即可迁移到反向扰动识别、双重扰动推理、表型筛选优先级排序和生物过程解释等任务。PertMind进一步生成了生物特征，这些特征在跨多尺度下游任务中支持了具有竞争力的基因、细胞和供体表征。这些结果支持以下假设：对实验终点的强化可以集中预训练模型已可访问的可重用生物策略。更广泛地说，扰动衍生的强化学习为将不断扩大的实验图谱转化为通用生物推理的训练环境提供了一条可扩展的途径。

## Abstract
Large language models can describe mechanisms, yet scalable post-training still depends on costly, manually curated biological reasoning traces. Here we show that cellular perturbation atlases can instead become reinforcement-learning environments, where measured gene responses provide computable rewards for biological reasoning. We introduce PertMind, which combines trusted-trajectory supervised initialization with gene-, pathway-, and format-level reinforcement signals. Trained only on forward perturbation-response prediction, PertMind improved response inference in unseen cellular contexts while retaining general language capabilities. It also transferred without task-specific post-training to reverse perturbation identification, double-perturbation reasoning, phenotypic-screen prioritization, and biological-process interpretation. PertMind further generated biological profiles that supported competitive gene, cell, and donor representations across multiscale downstream tasks. These results support the hypothesis that reinforcement on experimental endpoints can concentrate reusable biological strategies already accessible to pretrained models. More broadly, perturbation-derived reinforcement learning offers a scalable route for transforming expanding experimental atlases into training environments for general-purpose biological reasoning.

### 2. 论文提出的方法论：核心思想、关键技术细节

PertMind 以 Qwen3-4B Base 为起点，采用“**可信轨迹 SFT 初始化 + 通路监督 GRPO 强化学习**”的三阶段流水线。

**（1）问题定义（三元组分类）**
- 查询定义为三元组 x = (c, d, g)：细胞系 c、小分子药物 d、目标基因 g。
- 任务：预测目标基因 g 在药物 d 处理下于细胞系 c 中的响应方向，标签为 Y = {Up, Down, No}（上调、下调、无显著变化）。
- 标签由 Tahoe-100M 预计算的 pseudobulk DESeq2 统计量（log₂FoldChange、padj、baseMean）根据预设阈值自动分配。

**（2）可信轨迹 SFT 初始化**
- 仅靠稀疏的三分类终端奖励难以训练出结构化的推理行为，因此先从 Base 模型中采样候选轨迹，并筛选出“可信轨迹”（满足五条验证标准：最终标签正确、格式合规、未声称访问隐藏数据、实体关系有据可查、推理链完整）。
- 使用**平衡微调（Balanced Fine-Tuning, BFT）** 加权方案对筛选出的轨迹进行一轮 SFT，得到 RL 初始化策略 π_θSFT，作为后续 GRPO 的起点和 KL 正则参考。

**（3）通路监督 GRPO 强化学习**
- 对每个查询 x 从当前策略采样 G=8 条响应，每条响应包含：结构化通路方向预测、机制解释、最终基因标签。
- 奖励由三部分组成：
  - **基因级奖励 R_gene**：终端标签是否正确（二元指示，正确为 1，否则为 0），是最主要的目标。
  - **通路级奖励 R_pw**：对候选 Reactome 通路列表（最多 3 个，包含目标基因）中的通路方向预测，与条件级转录通路响应代理标签比较。该代理从非目标成员的协同转录响应中计算，且不确定状态（uncertain）不计入评分。
  - **格式奖励 R_fmt**：输出是否包含所有必需字段、标签是否合法、终端答案是否唯一。
- 总奖励为 R = R_gene + λ_pw·m_pw·R_pw + λ_fmt·R_fmt，且权重满足 λ_pw + λ_fmt < 1，确保任何辅助奖励组合都无法压倒正确基因标签的优先级。
- 采用 GRPO 算法进行组内标准化、置信度加权，并对全部分数做 KL 正则（以冻结的 SFT 策略为参考），防止政策漂移和灾难性遗忘。

**（4）严格的泄漏控制**

- 开发域内 90:10 划分训练/验证，按细胞系和标签分层。
- 当前查询的目标基因标签、差异表达统计量、通路代理标签均不进 prompt；检索池仅限训练域，且排除当前查询及其重复测量。

### 6. 论文的主要结论与发现

- **扰动端点强化可训练可重用推理策略**：仅以正向扰动响应预测为目标进行 RL 训练，PertMind 在未见细胞系上提升响应推断能力，且保留了通用语言能力。

- **机制归因**：基因级奖励提供终端选择压力，通路级奖励提供结构化中间监督（仅路径文字无法替代），二者互补。消融实验和预训练采样分析支持“选择-集中”解释——正确结论已存在于 Base 模型采样分布中，RL 的作用是将概率集中到有效策略上。
- **RL 在生物学后训练中的新范式**：实验测量数据可以作为语言模型强化学习的奖励来源，不依赖人工编写推理过程。将扰动资源视为训练环境，为通用生物推理的规模化训练开辟新路径。

### 7. 优点

- **新颖的训练范式**：将大规模实验图谱转化为强化学习环境，以实验终点为奖励，绕开人工推理轨迹的标注瓶颈，具备可规模化潜力。
- **多层次奖励设计**：基因级（终端正确性）+ 通路级（结构化中间一致）+ 格式级（可解析性）的奖励组合，在不泄露查询标签的情况下提供了丰富的学习信号，且奖励权重设计确保基因标号的优先级不可被辅助奖励超越。
- **严格的泄漏控制**：按细胞系划分训练/测试、检索与通路代理仅使用结果无关信息、查询标签隔绝于 prompt——这些都显著增强了结果可信度。
- **跨任务迁移验证充分**：正向 → 反向、单扰动 → 双扰动、响应预测 → 表型筛选 → 过程命名、文本 → 多尺度表征，任务方向、输出类型、尺度和执行模型均有变化，使得“涌现性生物推理”的论证更加充实。
- **表征层级化建构**：从基因描述出发，经由表达加权与注意力聚合，自然形成基因-细胞-供体三层表示体系。同一来源支持多个下游任务，文本知识充当符号知识与数据模型之间的接口。

### 8. 不足与局限

- **终端奖励可能助长短路学习**：模型可能学会预测正确端点而无需真正重构生物机制，自由文本轨迹只可审计但无法在因果层面验证。
- **通路奖励是转录代理**：基于通路成员的协同转录响应而非蛋白质活性、代谢通量或真正的通路激活，与真实机制有一定距离。
- **评估覆盖范围有限**：仅涉及小分子扰动，未涵盖遗传扰动（CRISPR）；读出仅为转录组，未覆盖染色质、蛋白、代谢等多组学层；组织类型、疾病状态、剂量窗口等生物多样性覆盖不足。
- **下游任务知识迁移的因果归因有限**：部分跨任务表现虽符合“涌现性”的操作性定义，但无法直接证明模型内部确实组合了候选效应或忠实还原了推理过程。
- **检索与知识源偏差**：知识图谱和模型生成的信任轨迹可能含遗漏、注释错误或历史偏向（如偏重研究充分的基础基因、药物、通路），从而在训练与推断中放大部分偏差。
- **表示学习的边界**：PertMind 嵌入需要任务特定投影和下游监督，其性能同时反映语言先验和任务适配器的作用，而非一个通用充分的固定表示。
