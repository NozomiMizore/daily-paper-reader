## 摘要
细胞绘画显微镜技术能够捕捉细胞在化学或遗传扰动后的变化。将这些图像与产生这些图像的扰动联系起来，可以使大规模的成像筛选更易于搜索和解释，但由于生物效应微妙且技术差异显著，这一任务仍然困难重重。我们提出了MorphoCLIP，一种对比模型，它能将细胞绘画特征与化合物、CRISPR敲除和ORF过表达的文本描述相关联。该模型保持其视觉和语言骨干网络冻结，仅训练一个紧凑的跨通道模块和投影层，因此可以在单个消费级GPU上进行训练。在留出的CPJUMP1数据上，MorphoCLIP实现了双向搜索：从细胞图像到其扰动描述，以及从描述到匹配的细胞图像。在这两种情况下，正确匹配出现在前十名结果中的频率远高于随机预期。加入重复对齐损失可以使重复实验得到的特征更加一致，尽管这一改进尚未转化为可靠的基因-化合物匹配。基因感知标签和板校正也未显示出一致的检索优势。这些发现表明，文本监督有助于组织化学和遗传的细胞绘画数据。然而，将化合物与遗传扰动相匹配仍然是一个悬而未决的问题。

## Abstract
Cell Painting microscopy captures how cells change after a chemical or genetic perturbation. Connecting these images to the perturbations that produced them could make large imaging screens easier to search and interpret, but the task remains difficult because biological effects are subtle and technical variation is substantial. We introduce MorphoCLIP, a contrastive model that links Cell Painting profiles with text descriptions of compounds, CRISPR knockouts, and ORF overexpressions. The model keeps its vision and language backbones frozen and trains only a compact cross-channel module and projection layers, so it can be trained on a single consumer GPU. On held-out CPJUMP1 data, MorphoCLIP searches in both directions: from a cell image to its perturbation description and from a description to matching cell images. In both cases, a correct match appears among the top ten results much more often than expected by chance. Adding a replicate-alignment loss makes profiles from repeated experiments more consistent, although this improvement does not yet translate into reliable gene-compound matching. Gene-aware labels and plate correction also show no consistent retrieval benefit. These findings suggest that text supervision can help organize chemical and genetic Cell Painting data. Matching compounds with genetic perturbations, however, remains an open problem.

## 一、论文的核心问题与整体含义

- **研究背景**：细胞绘画（Cell Painting）显微成像技术利用五种荧光染料标记细胞主要结构，能捕捉细胞在化学或遗传扰动（化合物处理、CRISPR 敲除、ORF 过表达）后的形态变化，为表型药物发现提供高通量视角。
- **核心难题**：将细胞图像与其对应的扰动来源关联起来非常困难，原因有三：
  1. **生物效应微妙**：扰动引发的形态变化往往细微，而被技术噪声掩盖；
  2. **技术变异显著**：不同批次、板位、成像日期的光照、染色和焦距差异可能强于生物学信号；
  3. **标签不完美**：生物学相似性并非简单的正/负二分——不同化合物可能共享靶点，基因敲除与化合物可能通过不同机制影响同一通路。
- **研究意义**：若能将大规模成像筛选中的图像与扰动文本自动匹配，将极大提升筛选数据的可搜索性和可解释性，助力药物研发。论文作者将"表型药物发现（phenotypic drug discovery）"作为宏观应用背景，强调该方法对传统靶点特异assay的补充价值。

## 二、论文提出的方法论

### 总体思路

MorphoCLIP 借鉴 CLIP（Contrastive Language-Image Pretraining）范式，将细胞绘画图像（孔/well 级）与扰动描述文本映射到同一归一化的嵌入空间（512 维），使匹配的图像–文本对具有高余弦相似度，不匹配的对距离更远。其核心特点是**视觉与语言骨干网络完全冻结**，仅训练小型跨通道模块和投影层（约 1400 万参数），大幅降低训练开销。

### 图像分支

1. **通道编码**：每个视野（site）的 5 个荧光通道（线粒体、肌动蛋白、高尔基体/质膜、内质网、DNA/细胞核）各自缩放至 224×224，复制为三通道后送入冻结的 **DINOv3 ViT-L/16**（约 3 亿参数），每个通道得到 1 个 1024 维 CLS token。
2. **特征缓存**：通道 token 预先计算并缓存到磁盘，训练时不再运行视觉骨干。
3. **CrossChannelFormer（CCF）**：一层、四头的 transformer，对 5 个通道 token 加可学习通道编码后进行跨通道信息融合，通过聚合 token 输出单个 site 表征（1024 维）。这是可训练参数的主要组成部分。
4. **Site 池化**：对一个孔的所有有效 site 表征做掩码平均，得到孔级向量，不依赖 site 数量或顺序。
5. **投影头**：两层 MLP（LayerNorm + GELU + Dropout p=0.3），映射到 512 维并做 L2 归一化。

### 文本分支

- 为每类扰动构建模板化 prompt（使用 CPJUMP1 元数据及 ChEMBL、UniProt 外部注释）：
  - **化合物**：细胞系、化合物名称、SMILES 结构、已知靶基因、靶蛋白功能、扰动类型；
  - **CRISPR**：基因符号、基因描述、基因功能、扰动类型；
  - **ORF**：基因符号、基因描述、基因功能、扰动类型；
  - **阴性对照**：DMSO 载体对照描述。
- 每个扰动标识符（`broad_sample`）对应一条 prompt，同一扰动的重复孔共享文本向量。
- 冻结的 **BioClinical ModernBERT**（1.5 亿参数）编码 prompt，取 768 维 CLS token，经可训练投影头映射到 512 维共享空间。

### 训练目标

1. **连续加权对比损失（CWCL）**：不同于标准 InfoNCE 将所有非匹配对视为同等负样本，CWCL 采用软标签亲和矩阵 W：
   - 同一扰动赋权重 1；
   - 不同扰动但**靶基因重叠**的样本赋权重 α（超参数，基础模型取 α=0，软标签消融取 α=0.6）；
   - 其余为 0。
   - 损失对行归一化的软标签与 logits softmax 交叉熵，包含图像→文本和文本→图像两个方向。
2. **重复对齐损失（Replicate Loss）**：在批内对同一扰动的重复孔做图像–图像对比学习，直接拉近重复孔之间的距离。权重 λrep（消融中取 0.3），与文本损失共享学习温度。基础模型 λrep=0。
3. **扰动感知批次采样**：按扰动分组配对，将重复孔打包进同一批次以支持重复损失。
4. **条件相对板偏移校正（可选）**：由于 CPJUMP1 中板与实验条件高度绑定，直接减去板均值会去除细胞系、扰动类型和时间点等有用信息。因此计算板均相对同一条件（condition）内其他板均值的偏移 δ，将图像嵌入减去该偏移并重新归一化。

### 优化细节

- AdamW（lr=1e-4，weight decay=0.2），batch size=256，FP16 混合精度，梯度裁剪 1.0；
- 100 步线性预热 + 余弦退火；温度参数可学习，初始 ln(1/0.07)；
- 基础模型训练 100 epoch；消融实验 30 epoch + 早停（8 epoch 无改善）；
- 验证损失仅用文本项，避免重复损失影响模型选择。

## 三、实验设计

### 数据集

- **CPJUMP1 pilot**（JUMP Cell Painting Consortium 发布的标准公开基准），包含：
  - 303 个小分子化合物；
  - 160 个 CRISPR 敲除；
  - 176 个 ORF 过表达；
  - 在 U2OS 和 A549 两种细胞系中测量，多数扰动类型含两个时间点；
  - 每个孔含多个视野 × 5 个荧光通道（3 个明场通道未使用）。

### 数据划分

- 按扰动（而非按孔）划分，固定哈希 80/10/10 分为训练/验证/测试集，确保同一扰动的重复孔不跨 split。
- 验证集：2220 孔、98 个扰动；测试集：1860 孔、86 个扰动；排除对照孔。

### 评估协议

1. **跨模态检索**：孔级图像→文本、孔级文本→图像、扰动级（孔嵌入平均后）双向检索，报告 Recall@{1,5,10} 和中位排名，并给出解析随机基线。
2. **标准 CPJUMP1 benchmark**：使用官方参考流程（fp32 编码、减阴性对照均值、40 块合格板），评估三个任务：
   - **重复性（Replicability）**：同一扰动的重复孔之间能否互相检索；
   - **靶点匹配（Target matching）**：同一类型扰动内共享靶点的扰动之间能否匹配；
   - **基因–化合物匹配（Gene–compound matching）**：跨扰动类型能否将化合物与靶点相同的遗传扰动匹配。
   - 指标为 mAP 和通过显著性检验的扰动比例。

### 对比方法

- **CellProfiler**：传统手工特征管线，引用其已发表的 CPJUMP1 靶点匹配范围；
- **CellCLIP**：最接近的文本监督基线，报告其发表结果并运行官方 checkpoint 做同流程对比（注意其额外使用 KernelPCA 校正，对比为近似）；
- **CWA-MSN**：批量效应校正方法，但研究数据集不同，无法直接数值比较。

### 消融实验设计

以"100 epoch + 随机批次 + 二元标签 + 无重复损失 + 无板校正"的基础模型为参照，另设共享控制（30 epoch 随机批次），随后逐一加入：基因感知软标签（α=0.6）、重复对齐损失（λrep=0.3）、条件相对板偏移，以及三者组合。共 6 组主要对比配置，统一 seed 42、batch size 256、相同数据划分。

## 六、主要结论与发现

1. **跨模态检索显著优于随机**：在留出测试集上，扰动级约 2/5 查询的正确匹配进入前十（R@10 约 37–44%，随机基线约 10–12%），约为随机水平的 3 倍以上；验证与测试表现相近，说明模型学到的是形态–文本关系而非记忆训练数据。
2. **重复对齐损失有效但并不充分**：该损失将所有 12 个 benchmark track 的重复性 mAP 从 0.298 提升至 0.343，组合模型更达 0.369——但这是因为它直接优化了 benchmark 所测的重复性指标，不能视为生物学理解的提升。
3. **基因–化合物匹配仍然失败**：所有变体几乎无法通过显著性阈值，池化 mAP 无明显排序，这是论文强调的核心未解问题。
4. **基因感知软标签和板偏移无一致收益**：在检索任务上各消融差异过小，无法确认可靠改进。
5. **文本监督的整体意义**：MorphoCLIP 成功作为"扰动身份"和"重复结构"的检索模型，但尚不能作为通用生物学机制模型。

## 七、优点

- **极致资源效率**：冻结双骨干 + 特征缓存 + 仅训练 1400 万参数，在单张 16 GB 消费级 GPU 上即可完成，极大降低了该方向的研究门槛。
- **统一的跨模态表示**：以文本为中介，首次在同一模型内覆盖化合物、CRISPR 敲除和 ORF 过表达三类扰动（对比 CLOOME/MolPhenix 仅限化合物），支持自然语言查询。
- **方法设计细致**：
  - 逐通道编码 + 跨通道 transformer，合理处理 5 通道显微图像（区别于将 5 通道简单当作 RGB 的做法）；
  - 软标签 CWCL 考虑了靶点重叠的生物学相似性；
  - 条件相对板偏移避免了朴素板校正丢失条件信息的陷阱；
  - 扰动感知批次配合重复损失设计巧妙。
- **评估严谨**：按扰动划分数据防止泄漏；给出解析随机基线；对每次消融的差异幅度有清醒认识，没有过度解读小差异；坦率报告基因–化合物匹配失败。
- **可复现性**：代码、配置、划分清单、评估工具全部开源。

## 八、不足与局限

- **核心任务未突破**：基因–化合物匹配这一最有生物学价值的任务在所有配置下均基本失败，限制了方法的实际应用价值。
- **标注粒度过粗/不一致**：训练用的"主要靶点"注释与 benchmark 使用的"更宽靶点列表"不匹配，可能是跨模态匹配失败的重要原因，但论文未深入验证这一假设。
- **实验覆盖有限**：
  - 仅单个数据集、两种细胞系；未在更大、更多样的 JUMP 全量语料上验证跨站点、跨细胞系迁移；
  - 未做 prompt 消融——无法判断 SMILES 和基因功能描述等文本成分对检索的实际贡献；
  - 与现有方法的对比多为近似或非直接，缺乏统一协议下的全面横向比较。
- **统计功效不足**：单检索扰动变化约 1 个百分点，而消融差异多为数个百分点（仅涉及数个扰动），论文自己也承认无法建立可靠结论；benchmark 显著性检验的随机性进一步削弱了 fraction retrieved 指标的可比性。
- **方法固有矛盾**：重复损失提升的是 benchmark 直接优化的量，存在"优化目标即评估指标"的循环性，难以证明其生物学价值。
- **技术应用局限**：以文本描述为中心的方法依赖外部注释质量（ChEMBL、UniProt），对于无良好注释的新扰动，文本分支的表达力和泛化能力存疑。
