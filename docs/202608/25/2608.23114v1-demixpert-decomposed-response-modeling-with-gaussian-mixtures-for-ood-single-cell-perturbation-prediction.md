## 摘要
预测未见遗传扰动下的全转录组响应仍是一项重大计算挑战，因为准确预测需要同时恢复扰动特异的转录变化和异质性细胞响应。现有方法常常将确定性响应结构与随机群体水平变异纠缠在一起，导致主导的共享模式掩盖较弱的扰动特异信号，并损害分布建模。为解决这些问题，我们提出\textbf{DeMixPert}，一种用于分布外（OOD）单细胞扰动预测的基于高斯混合的分解响应建模方法。DeMixPert将扰动诱导的变化分解为基线状态依赖的系统性响应、扰动特异响应和群体水平变异。系统性成分来源于从对照细胞表达编码的基线状态，而扰动特异成分则从预训练的目标嵌入推断以实现未见目标泛化。DeMixPert使用高斯原型可逆网络对群体水平变异建模，并根据基线状态和扰动条件自适应组合可重用高斯原型。所得混合分布被映射为条件特异的变异分布。采样变异与系统性和扰动特异成分整合，并与基线状态联合解码以重建扰动细胞的基因表达。实验结果表明，DeMixPert有效捕获异质性单细胞扰动响应，并在未见扰动设置下实现优越性能。源代码将在论文发表后公开提供。

## Abstract
Predicting transcriptome-wide responses to unseen genetic perturbations remains a major computational challenge because accurate prediction requires recovering both perturbation-specific transcriptional shifts and heterogeneous cellular responses. Existing methods often entangle deterministic response structure with stochastic population-level variation, causing dominant shared patterns to mask weaker perturbation-specific signals and impair distributional modeling. To address these challenges, we propose \textbf{DeMixPert}, an approach for Decomposed response Modeling with Gaussian Mixtures for Out-Of-Distribution (OOD) single-cell Perturbation prediction. DeMixPert decomposes perturbation-induced changes into a basal-state-dependent systematic response, a perturbation-specific response, and population-level variation. The systematic component is derived from the basal state encoded from control-cell expression, whereas the perturbation-specific component is inferred from pretrained target embeddings for unseen-target generalization. DeMixPert models population-level variation using a Gaussian prototype Invertible Network and adaptively combines reusable Gaussian prototypes according to the basal state and perturbation condition. The resulting mixture is mapped to a condition-specific variation distribution. Sampled variations are integrated with the systematic and perturbation-specific components, followed by joint decoding with the basal state to reconstruct perturbed-cell gene expression. Experimental results show that DeMixPert effectively captures heterogeneous single-cell perturbation responses and achieves superior performance across unseen-perturbation settings. The source code is made publicly available upon publication.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：单细胞遗传扰动预测中，如何准确预测**未见过（OOD）的遗传扰动**下的转录组响应。
- **具体挑战**：一个扰动响应包含三个互相纠缠的部分：① 基线细胞状态带来的系统性响应；② 扰动特异的转录效应；③ 群体水平的异质性变异（即同一扰动下细胞亚群分布）。现有方法通常把整个扰动响应当作一个整体（monolithic）来建模，导致：
  - 共享的系统性模式掩盖较弱的扰动特异信号；
  - 难以准确估计条件特异的细胞群体分布；
  - OOD 泛化能力受限。
- **整体含义**：作者认为准确预测需要将确定性响应结构与随机群体变异进行**显式分解**，分别建模、再整合，从而同时恢复扰动特异信号与异质性分布。

## 2. 论文提出的方法论

### 2.1 核心思想
- 将扰动响应分解为三个部分：
  \[
  \hat{r}_i = g_i + a_p + \epsilon_i
  \]
  - \(g_i\)：基线状态依赖的**系统性响应**（由对照细胞编码的基底状态推断）；
  - \(a_p\)：**扰动特异响应**（由预训练 scGPT 基因嵌入推断）；
  - \(\epsilon_i\)：**群体水平变异**（由高斯原型可逆网络建模）。

### 2.2 关键技术细节
1. **确定性响应中心学习（Deterministic Response Center Learning）**
   - 三个编码器：\(E_s\)（基底状态编码器）、\(E_{sys}\)（系统性响应编码器）、\(E_{pert}\)（扰动响应编码器）。
   - \(s_i = E_s(x_j^0)\)，\(g_i = E_{sys}(s_i)\)，\(a_p = E_{pert}(e_p)\)，其中 \(e_p\) 来自预训练 scGPT 的基因嵌入（单基因直接取嵌入，组合扰动取平均）。
   - 确定性响应中心：\(\bar{r}_i = g_i + a_p\)。

2. **高斯原型可逆网络（Gaussian Prototype Invertible Network）**
   - 全局共享 \(K\) 个对角高斯原型（用 EM 算法从训练目标残差中估计）。
   - 条件权重预测：
     \[
     \alpha_i = \text{softmax}(\text{MLP}(\text{concat}(s_i, a_p)))
     \]
     根据细胞状态和扰动条件自适应组合高斯原型。
   - 条件混合分布：\(P(z|\alpha_i) = \sum_k \alpha_{ik} \mathcal{N}(z; \mu_k, \text{diag}(\sigma_k^2))\)。
   - 使用可逆网络（RealNVP 风格的 additive coupling layers）将源样本 \(z_i\) 映射为变异样本 \(\epsilon_i\)。
   - 每一层耦合层中，未改变的特征子集与高斯原型进行匹配（计算责任权重），并与基于条件表示的原型调制系数结合，产生平移变换。
   - 训练时，利用逆变换将目标变异 \( \epsilon_i^* = r_i^* - \bar{r}_i\) 映射回高斯混合空间，计算负对数似然作为监督。

3. **表达解码器**
   - 将基底状态 \(s_i\) 和预测响应 \(\hat{r}_i\) 拼接后解码，重建扰动后表达：\(\hat{x}_i^p = D_\psi(\text{concat}(s_i, \hat{r}_i))\)。

4. **训练目标**
   - 四部分损失：
     - 响应对齐损失 \(L_{\text{align}}\)（MSE，对齐响应潜变量）；
     - 群体变异似然损失 \(L_{\text{gm}}\)（负对数似然）；
     - 表达重建损失 \(L_{\text{rec}}\)（含从目标响应重建、从零响应重建对照表达）；
     - 分布损失 \(L_{\text{dist}}\)（条件水平能量距离）。
   - 总损失：\(L = L_{\text{align}} + \lambda_{\text{gm}} L_{\text{gm}} + L_{\text{rec}} + L_{\text{dist}}\)。

## 6. 主要结论与发现

- DeMixPert 通过显式分解确定性响应与随机变异，能更好地恢复**扰动特异的转录信号**，避免系统性共享模式掩盖弱信号。
- 高斯原型可逆网络可以根据细胞状态和扰动条件**自适应组合共享原型**，有效估计条件特异的群体分布。
- 实验证实：
  - 在 OOD 单基因和组合扰动预测上均达到最先进水平；
  - 去除系统性响应成分后，扰动响应空间的**聚类纯度显著提高**（Adamson 0.555→0.825，Replogle 0.308→0.769），证明分解有助于去混淆；
  - 原型权重差异与群体分布差异显著正相关（\(\rho=0.462/0.512\)，Mantel \(p<0.001\)），说明原型组合机制确实编码了有意义的扰动结构。
- 整体上，DeMixPert 为 OOD 单细胞扰动预测提供了一种结构化的分解建模框架，同时提升了预测准确性和分布保真度。
