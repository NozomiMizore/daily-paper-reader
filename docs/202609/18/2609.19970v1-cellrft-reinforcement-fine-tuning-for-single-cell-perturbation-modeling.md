## 摘要
预测细胞对扰动的响应有助于基因功能、疾病机制和治疗策略的研究。尽管单细胞扰动建模取得了进展，现有模型通常优化代理损失，而这些损失并不直接反映评估所使用的生物学标准，因此更好的数据拟合未必带来更好的生物学预测。为解决这一不匹配问题，我们提出 CellRFT，一种强化微调框架，将生物学评估用作直接训练反馈。CellRFT 采用策略梯度优化，从生成细胞群体的不可微评估中学习，并通过分层奖励聚合整合多种生物学奖励。综合实验表明，CellRFT 可适用于不同的预训练模型，并能有效改进扰动预测；揭示了优化某一生物学标准可能有助于或妨碍其他标准；还表明互补奖励可以提升那些未直接优化的标准，为探究生物学指标如何塑造模型行为提供了一种途径，并有可能为评估设计提供启示。代码将公开。

## Abstract
Predicting cellular responses to perturbations supports the study of gene function, disease mechanisms, and therapeutic strategies. Despite advances in single-cell perturbation modeling, existing models typically optimize surrogate losses that do not directly reflect the biological criteria used for evaluation, so better data fitting need not yield better biological predictions. To address this mismatch, we introduce \textbf{CellRFT}, a reinforcement fine-tuning framework that uses biological evaluation as direct training feedback. CellRFT uses policy-gradient optimization to learn from non-differentiable evaluations of generated cell populations and integrates multiple biological rewards through hierarchical reward aggregation. Comprehensive experiments demonstrate CellRFT's applicability across different pretrained models and effectiveness in improving perturbation prediction, reveal that optimizing one biological criterion can help or hinder others, and show that complementary rewards can improve criteria beyond those directly optimized, offering a way to probe how biological metrics shape model behavior, with the potential to inform evaluation design. ## 2. 方法论

- **核心思想**：把预训练生成模型视为策略，把生物学评估指标视为奖励，通过策略梯度优化生成更符合生物学评价的细胞群体。
- **关键挑战**：
  - 许多生物指标包含阈值、排序、基因集合操作，**不可微**。
  - 生物评价通常在**细胞群体层面**计算，而常见生成模型 RL 需要单样本奖励。
  - 多个生物指标如何整合为统一奖励尚不明确。
- **总体流程**：
  1. 对每个扰动条件，从当前策略采样 \(G\) 组候选细胞群体，每组 \(B\) 个细胞。
  2. 用 Cell-Eval 类指标计算每组候选的多个生物奖励。
  3. 对奖励进行**分层聚合**：先在每个评估类别内平均，再在类别间平均，使各评估类别总权重相等。
  4. 在每个扰动的候选组内对聚合奖励做标准化，得到组相对优势 \(A^{(g)}\)。
  5. 将同一候选群体的优势共享给该组所有细胞和所有去噪步。
  6. 使用类似 GRPO/PPO 的裁剪目标更新生成模型，最大化高奖励候选轨迹的似然。
- **公式与算法要点（文字说明）**：
  - 目标函数为最大化期望生物奖励：\(\max_\theta \mathbb{E}_{\hat X \sim p_\theta}[r(\hat X; X_{\text{ctrl}}, X_{\text{pert}}, c, \tau)]\)。
  - 分层奖励：\(R^{(g)} = \frac{1}{|C|}\sum_{k\in C}\frac{1}{|J_k|}\sum_{j\in J_k} r_j(\hat X^{(g)})\)，避免指标多的类别主导优化。
  - 优势：\(A^{(g)} = (R^{(g)} - \text{mean}) / \text{std}\)，在扰动组内归一化。
  - 策略优化：使用裁剪的重要性权重目标 \(J_{\text{CellRFT}}(\theta)\)，其中重要性比率为当前策略与旧策略在去噪转移上的密度比。
- **算法特征**：
  - 不需要对评估器反向传播。
  - 通过群体级采样与共享优势，连接“单细胞生成轨迹”和“群体级生物评价”。

## 6. 主要结论与发现

- **CellRFT 可适配不同预训练模型并提升扰动预测**：
  - 应用于 PerturbDiff（Scratch）时，13 个报告指标全部提升。
  - 应用于 PerturbDiff（Finetuned）时，9 个指标进一步提升。
  - 两个变体在 DEOver、DEPrec、AUROC、AUPRC 上均优于所有非 CellRFT 基线。
- **提升集中在扰动诱导的基因表达响应指标**：
  - Scratch 变体中，DEOver 从 0.190 升至 0.236，LFCSpear 从 0.342 升至 0.452，AUROC 从 0.625 升至 0.672，AUPRC 从 0.210 升至 0.270。
- **奖励效果存在耦合与冲突**：
  - 优化单个生物指标通常能提升目标指标，但多数情况下会损害其他指标。
  - 例如 DESigRec 单独优化时目标提升明显，但跨指标表现分歧最大。
  - 将指标纳入联合奖励也不保证其一定提升：Finetuned 变体在差异表达指标上升，但三个 PDS 指标下降。
- **互补奖励可缓解权衡**：
  - C2（扰动判别）+ C3（差异表达保真度）是唯一能提升全部 11 个指标的两两类别组合。
  - CellRFT 分层聚合平均增益为 6.5，高于 Flat mean 的 5.9 和 DEOver-only 的 5.2，且提升全部 11 个指标。
- **奖励之间存在非对称支持关系**：
  - PDS L1 对 PDS cos 的支持强于反向，PDS L1 是 hub，PDS cos 是 authority。
  - PDCorr 与 DirAgr 虽属不同评估类别，却形成最接近的响应对。
  - DEPrec 虽然与 DEOver 聚类较近，但获得的组内支持有限。
- **紧凑奖励子集可带来广泛提升，但存在 reward hacking 风险**：
  - 4 奖励子集导致 recall 从 0.382 升至 0.833，但 precision 和 PDCorr 低于预训练基线。
  - 移除 DESigRec 后的 3 奖励变体仅用三个直接奖励即可提升 10/11 个指标。
  - 全奖励 CellRFT 在整体权衡上更优。

## 7. 优点

- **问题定位清晰**：明确指出训练目标与生物评估目标之间的不匹配，并用 RL 直接优化评估反馈。
- **方法通用性**：不依赖特定生成模型，可应用于不同预训练扰动预测模型。
- **解决粒度不匹配**：通过“候选细胞群体”采样和群体优势共享，适配群体级生物评价。
- **分层奖励聚合设计合理**：先类别内平均、再类别间平均，避免指标数量多的类别主导训练。
- **实验分析深入**：不仅报告性能提升，还系统分析单奖励、类别组合、聚合规则、指标聚类和奖励支持关系。
- **具有评估设计启示**：揭示不同生物指标之间的协同、冲突
