## 摘要
预测特定扰动下的转录反应对于理解细胞调控机制和加速药物发现至关重要。单细胞RNA测序会破坏每个被测细胞，仅产生对照组和扰动组细胞的非配对群体。然而，现有方法通常以单细胞水平建模扰动预测，并假设细胞间存在一一对应关系，这与观测数据的非配对性质相冲突。为应对这一挑战，我们提出PopPert框架，该框架显式参数化群体水平的基因表达联合分布，以进行集体转录状态建模。给定对照组群体分布和扰动条件，PopPert预测扰动诱导的分布参数变化，从而消除了对细胞水平对应关系的需求，并降低了对单细胞噪声的敏感性。为有效捕获基因共表达模式，PopPert利用低秩高斯Copula建模跨基因统计依赖性并构建基因表达联合分布，同时允许对合成的扰动单细胞谱进行采样。在涵盖遗传扰动和化学扰动的多个单细胞基准测试中，PopPert在差异表达恢复、扰动效应估计和群体水平分布匹配方面均取得了卓越的整体性能。这些结果确立了群体水平联合分布学习作为从非配对单细胞群体预测转录反应的有效范式。PopPert的代码可在https://github.com/whd1125/PopPert公开获取。

## Abstract
Predicting transcriptional responses to specific perturbations is critical for understanding cellular regulatory mechanisms and accelerating drug discovery. Single-cell RNA sequencing destroys each measured cell, yielding only unpaired populations of control and perturbed cells. However, existing methods typically model perturbation prediction at the single-cell level and assume cell-to-cell correspondence, which conflicts with the unpaired nature of the observed data. To address this challenge, we propose PopPert, a framework that explicitly parameterizes population-level joint gene expression distributions for collective transcriptional state modeling. Given a control population distribution and a perturbation condition, PopPert predicts perturbation-induced changes in distribution parameters, eliminating the need for cell-level correspondence and reducing sensitivity to single-cell noise. To effectively capture gene co-expression patterns, PopPert leverages a low-rank Gaussian Copula to model cross-gene statistical dependencies and construct the joint gene expression distribution, additionally allowing sampling of synthetic perturbed single-cell profiles. Across multiple single-cell benchmarks spanning both genetic and chemical perturbations, PopPert achieves superior overall performance in differential expression recovery, perturbation effect estimation, and population-level distribution matching. These results establish population-level joint distribution learning as an effective paradigm for predicting transcriptional responses from unpaired single-cell populations. Code for PopPert is publicly available at https://github.com/whd1125/PopPert.

## 2. 方法论

**总体思想**

PopPert 将扰动预测视为群体状态（population state）之间的映射，分为三步：从对照组表达矩阵构建群体状态 → 基于扰动条件预测扰动组群体状态 → 从预测的联合分布中采样生成虚拟扰动细胞群体。完整流程为：

`X_ctrl → S_ctrl = (Θ_ctrl, s_ctrl) → Ŝ_pert = (Θ_pert, ŝ_pert) → X̂_pert`

### 群体状态的构建

**基因边缘状态（marginal state）：** 对每个基因分别拟合一个零膨胀截断高斯混合模型（zero-inflated truncated Gaussian mixture，ZI-GMM）：
- 点质量 δ₀ 捕获零表达（概率 π）
- 截断正态混合（K 个成分）捕获正值表达分布
- 每个基因的边缘状态表示为参数集合 θ = (π, {w, μ, σ})
- 另支持零膨胀负二项（ZINB）作为可选分布族

**跨基因依赖状态（cross-gene dependence state，Copula 空间）：** 为建模基因间的统计依赖关系，PopPert 构造了低秩高斯 Copula 状态。关键步骤：
- 边缘变换：通过 CDF 将表达值映射到概率区间（对零值做随机化处理以避免概率积分变换的歧义）
- 高斯变换：用标准正态分位数函数 Φ⁻¹ 将概率值转化为潜在高斯变量
- 相关性估计：计算多组潜在变量的经验相关矩阵
- 低秩因子化拟合：求解一个 G×G 相关矩阵的紧凑表达——通过因子载荷矩阵 A 和基因特异残差方差 ψ（从池化对照组估计得到，全程共享固定）构建因子+对角阵的协方差结构 Σ(s) = A diag(s)Aᵀ + diag(ψ)，用 r 维正因子强度向量 s 表示种群的特异性共表达状态（r = 32 为默认）

### 群体级扰动预测

**条件信息融合：** 采用多层 Transformer Decoder：
- 每个基因的边缘参数作为一个 token；依赖状态 s 额外作为一个 token
- 遗传扰动和基因身份采用 scGPT 预训练基因嵌入；化学扰动采用 Morgan 分子指纹
- 细胞上下文经全连接层编码
- 借助交叉注意力融合条件与输入状态

**残差预测策略：** 不直接预测目标参数，而是预测控制状态的扰动诱导残差偏移。通过 sigmoid/softmax/exp 等变换保证参数的合法性：
- 零概率：logit 空间加残差再经 sigmoid
- 混合权重：log 空间加残差再经 softmax
- 均值：直接加残差
- 标准差：log 尺度乘性更新
- 因子强度：s_pert = s_ctrl ⊙ exp(Δlog s)

**损失函数：**
- 边缘状态用目标分布下的负对数似然（NLL）作为损失，即通过目标分布采样计算预测分布的交叉熵
- 依赖状态用预测/目标 log 空间中因子强度向量的均方误差（L2）
- 总损失 L = L_marg + λ_dep L_dep，默认 λ = 0.2

### 从联合分布生成基因表达

- 通过共享因子得分 h ~ N(0, diag(s)) 和基因特异噪声 ξ ~ N(0, diag(ψ)) 的低秩分解采样，避免存储稠密 G×G 矩阵
- 合成向量 y = Ah + ξ，再标准化为标准正态 Copula 向量 z
- 取 Φ(z) 为 Copula 分位数，经预测边缘分布的广义逆 CDF（inverse CDF）映射回基因表达空间 → 得到合成的扰动单细胞谱

## 7. 优点与亮点

1. **概念性创新（建模与数据对齐）：** 将任务从单细胞级映射改造成群体级分布映射，直接回应了 scRNA-seq 数据的非配对本质，避免了对数据体产生虚假单细胞配对
2. **简洁而数据驱动的联合分布表示：** 用 ZI-GMM 处理边缘分布（直接适用于零膨胀的特征），采用低秩共享因子结构（A、ψ 共享来自对照池，s 维度仅 r = 32），在有限参数下精准捕捉数千基因的基因共表达模式
3. **保留合成单细胞的采样能力：** 既可在群体分布层面预测，也可从所学联合分布中生成合成单细胞，这对下游 DE 分析等实用场景是必要的
4. **工程上的低依赖与通用性：** 浅层 Transformer + 残差预测 + 因子化生成，可在单张 A800 GPU 上完成；分布族可替换（ZI-GMM vs ZINB），支持药物/基因/多细胞上下文
5. **批判性视角：** 从“典型方法总是预测均值”的问题出发，比同类论文更好地强调了对评价指标的校准与维度覆盖。

## 8. 不足与局限性

1. **分布表示能力的边界：**
   - 因子载荷矩阵 A 与残差方差 ψ 被设定为“池化对照组固定”，意味着不同扰动只在因子强度的 r 维缩放上体现差异，限制了扰动的表示自由度，无法对极强或新型扰动依赖方向建模
   - 高斯 Copula 仅能描述线性/椭圆相关；非线性依赖、网络模块化等强逻辑可能无法被高效率捕获
2. **计算层面：** 论文承认 Copula 状态建设中一次性估计经验相关矩阵仍需 O(G²) 内存/时间开销；虽然预测与生成阶段的复杂度更低，但全基因组规模（>20k 基因）在预处理时的扩展性问题未彻底解决
3. **评估指标与公平性的局限：** E-Dist. 上在三个遗传数据集均名列第二，PopPert 相对 STATE 等模型的增益并非在所有分布指标上都成立；与最新的生成式（扩散/流匹配）基线（CellFlow、PerturbDiff、Unlasting）相比缺少比较；无统计显著性说明或置信区间报告
4. **依赖预训练嵌入与超参数：** 选择预训练 scGPT 嵌入与 Morgan 指纹会对性能有影响；默认的超参数（popul batch 128，λ_dep=0.2 等）在敏感性分析中的不同指标上具有不同最优，缺少自适应调整策略
5. **零膨胀混合模型假设的偏好：** 文献中常利用零膨胀负二项建模原始计数，而 PopPert 默认选择的是 log-normal 化连续输出的 ZI-GMM；当用户想要保留实际读段计数，精度可能下降（ZINB 实验表明其效果要弱于主实验中的 ZI-GMM 模型）
6. **未来工作缺口：** 未提供预测的校准不确定性度量；未放松固定共享因子载荷假设来解决跨上下文共享方向的问题
