## 摘要
AIVC（AI虚拟细胞）是一种可学习的、跨条件的细胞行为模拟器。预测细胞群体在转录层面如何响应基因扰动是一项核心任务。Perturb-seq 通过破坏性测序记录这种响应，因此对照细胞与受扰动细胞从未以配对形式被观测到，且同一条件下的细胞仍具有异质性和噪声。对单个细胞做回归会将采样变异吸收进所估计的效应中，而解释则需要可重复的群体效应。P2P（Perturbation-to-Perturbation）以随机的细胞集合视图作为其监督单元。来自同一条件的两个视图共享可重复的群体效应，其差异在于视图特有的变异。一个置换不变集合编码器概括对照群体，一个结构化编码器表示扰动 token、细胞背景、剂量与组合交互，一个门控将经验条件效应记忆与神经残差进行融合。一个异方差头预测群体均值与逐基因响应方差。在同一协议与五个随机种子下，相对于 GenePert、LinearPert、SLIM、Scouter 与 scPILOT，P2P 在 Adamson、Norman、Replogle K562 与 Replogle RPE1 上均取得最低的表达 RMSE 以及最高的 Effect Pearson、DEG F1 与 DEG 平均精度。在 Replogle K562 上，相对于在这两项指标上均为最强基线的 Scouter，Effect Pearson 从 0.643 提升至 0.702，DEG F1 从 0.067 提升至 0.178。

## Abstract
AIVC (AI Virtual Cell) is a learned simulator of cellular behavior across conditions. Predicting how a cell population responds transcriptionally to a genetic perturbation is a core task. Perturb-seq records that response by destructive sequencing, so a control cell and a perturbed cell are never observed as a pair, and cells under one condition remain heterogeneous and noisy. Regression on individual cells absorbs sampling variation into the estimated effect, whereas interpretation requires the reproducible population effect. P2P (Perturbation-to-Perturbation) takes a stochastic cell-set view as its supervision unit. Two views drawn from the same condition share a reproducible population effect and differ by view-specific variation. A permutation-invariant set encoder summarizes the control population, a structured encoder represents perturbation tokens, cellular context, dose, and combination interactions, and a gate blends empirical condition-effect memory with a neural residual. A heteroscedastic head predicts the population mean and gene-wise response variance. Under one protocol and five seeds, P2P attains the lowest expression RMSE and the highest Effect Pearson, DEG F1, and DEG average precision on each of Adamson, Norman, Replogle K562, and Replogle RPE1 relative to GenePert, LinearPert, SLIM, Scouter, and scPILOT. On Replogle K562, Effect Pearson rises from 0.643 to 0.702 and DEG F1 rises from 0.067 to 0.178 relative to Scouter, the strongest baseline on both metrics.

## 1. 核心问题与研究动机

- **背景**：AI 虚拟细胞（AIVC）旨在构建跨条件的细胞行为可学习模拟器。其中一项核心任务是预测细胞群体在转录层面对基因扰动的响应。
- **数据困境**：Perturb-seq 采用破坏性测序，因此**对照细胞与受扰动细胞从不以配对形式被观测**；同一条件下的细胞仍高度异质且含噪（细胞周期、应激状态、捕获效率等差异）。
- **方法学困境**：若在单个细胞层面做回归，采样变异会被吸收进所估计的效应中；而生物学解释需要的是**可重复的群体效应**。
- **核心洞察**：来自同一条件的两个随机细胞集合视图共享可重复的群体效应，仅差异于视图特有的采样噪声。因此可以用「集合视图」而非「细胞对」作为监督单元。
- **整体含义**：论文提出 P2P（Perturbation-to-Perturbation），将监督信号从细胞级重构为群体级，从而在无配对条件下学习条件效应。

## 2. 方法论

### 2.1 问题形式化与跨视图监督

- 记 G 为基因数；对背景 s、剂量 d、扰动 token 集 p，定义群体均值与条件效应：
  - `μ_{p,s,d} = E[x | p, s, d]`
  - `δ_{p,s,d} = μ_{p,s,d} − μ_{0,s}`
- 对每个集合用 `ViewSplit` 抽样两个随机视图（细胞充足时为不相交采样；条件较小时用有放回独立采样以维持视图大小）。
- 训练时：用**一个对照视图 + 条件元数据**预测**另一个扰动视图的均值**，并计算反向方向；损失比较预测值、相对匹配对照视图的效应、以及视图内二阶矩。
- 推断时：目标视图缺失，模型仅接收对照集合、扰动 token、背景、剂量与可选的**条件记忆**（由训练角色细胞计算）。
- 论文明确区分三类量：**细胞级状态**（单个表达向量）、**群体均值**（条件统计量）、**扰动效应**（共同背景下两群体均值之差）；P2P 优化后两者，细胞级观测仅用于构造集合统计量。

### 2.2 架构设计

- **置换不变群体编码（SetEncoder）**
  - 每个细胞经共享投影：`h_i = Dropout[GELU(LN(W_x x_i + b_x))]`
  - 得分网络生成归一化细胞权重 a_i，集合状态包含注意力加权摘要与无权重离散度摘要：
    - `h̄_a = Σ a_i h_i`，`h̄ = (1/n) Σ h_i`，`v = (1/n) Σ (h_i − h̄)²`
    - `h_set = MomentMLP([h̄_a, v])`
  - 所有操作跨细胞共享并接对称的求和/均值/方差，故对输入细胞置换不变；v 保留群体异质性的紧凑表示，无权重均值锚定实测对照基线。
- **结构化扰动与背景编码**
  - token 嵌入用掩码池化（padding 不贡献）：`e_p = Σ m_j E[p_j] / max(1, Σ m_j)`
  - 组合扰动时加入小型 pair-interaction MLP 的非线性修正 `q(e_p)`（单 token 时禁用）
  - 条件状态：`h_pert = LN(e_p + 1_{|p|>1} q(e_p) + E_s[s] + r(d))`
- **记忆门控效应预测**
  - 融合：`h_cond = Fusion(h_set, h_pert)`，`Δ_neural = DeltaHead(h_cond)`
  - 经验记忆：`m_{p,s,d} = mean(X^role_{p,s,d}) − mean(X^role_{0,s})`
  - 门控：`g = σ(α)`，`δ̂ = g·m_{p,s,d} + (1−g)·Δ_neural`，`μ̂ = mean(X_{0,s}) + δ̂`
  - α 初始化为 1.1，使记忆分支初始权重约 0.75，同时保留可训练残差；显式先验让模型在经验效应与学习残差之间插值。
- **异方差输出**：第二头预测逐基因 log 方差，`log σ̂² = clip(LogVarHead(h_cond), −8, 4)`；可选采样 `ỹ = μ̂ + ε·exp(½ log σ̂²)`，评估前将样本均值中心化到 μ̂。
- **效应中心的跨视图目标**（权重见下）
  - 高斯 NLL 0.35；效应 Smooth L1 1.50；效应相关 0.15；矩匹配 0.08；跨视图一致性 0.05
  - 交叉对（X⁰ᵃ→X^b_p 等）的 NLL 与效应损失以 0.25 权重计入直接项
  - 基因权重 `w_g = 1 + |δ_g| / (mean_k|δ_k| + ε)`，防止大量无变化基因主导效应方向
  - 矩项在 log 空间比较预测方差与目标视图方差；一致性项耦合两个视图的均值与 log 方差（在采样前计算）

### 2.3 群体解释与协议

- 若视图均值可写为 `ȳ_v = μ_{p,s,d} + η_v`、`c̄_v = μ_{0,s} + ξ_v`，且视图误差条件均值为零、两次抽样同分布，则 `E[ȳ_v] = μ`、`E[ȳ_v − c̄_v] = δ`。
- 角色划分固定：**train 用于优化与记忆构建，validation 用于选检查点，support 与 test 用于读出与打分**；小条件因有放回采样可能存在视图重叠，协议显式记录。

## 6. 主要结论与发现

- P2P 在 **全部四个数据集**上取得最低 Expression RMSE 与最高 Effect Pearson、DEG F1、DEG AP。
- 最大增益出现在规模较大的 Replogle 屏幕：
  - **K562**：RMSE 0.0499（最强基线 Scouter 0.0861）；Effect Pearson 0.6432 → **0.7018**；DEG F1 0.0671 → **0.1784**；DEG AP 0.2572。
  - **RPE1**：RMSE 0.0910、Effect Pearson 0.6609、DEG F1 0.2173、DEG AP 0.3120。
- Adamson 与 Norman 的绝对误差更小、表达相关性高，但效应类指标仍由 P2P 领先；**Expression Pearson 上 GenePert 在 Adamson/Norman 最高**，论文解释该指标主要反映共享表达基线，而效应指标因减去匹配对照群体而更具区分度。
- 消融显示：去掉双视图监督（RMSE 0.0987、Effect r 0.6412）、去掉记忆（RMSE 0.1049、DEG AP 0.2088）、去掉 pair interaction（RMSE 0.1123、DEG F1 0.1742）、去掉一致性/相关项（RMSE 0.1016）均使性能下降；**去掉异方差头反而略提高 Effect Pearson（0.6681）但降低 DEG AP 与表达指标**，体现点预测与方差目标之间的权衡。
- 群体空间可视化显示 P2P 样本从对照云向观测扰动均值移动；图结构诊断显示预测保留主导局部效应的符号模式；记忆辅助迁移读出表明集合表示与效应头可适配不同支持群体。

## 7. 优点

- **监督范式创新**：用同一条件的随机集合视图替代不可得的细胞配对，直接以群体统计量为学习目标，概念清晰且与生物学解释目标一致。
- **架构设计合理**：置换不变集合编码器（注意力摘要 + 离散度矩）、掩码 token 池化与 pair interaction、背景/剂量显式建模，能同时支持单基因与组合扰动。
- **统计先验与学习残差的显式融合**：门控在经验效应记忆与神经残差间插值，初始化使记忆分支主导，兼顾稳定性与可学习性。
- **均值与方差解耦**：异方差头与 log 空间矩匹配分离了「效应恢复」与「响应异质性」，并用 90% 预测区间等诊断单独评估不确定性。
- **评估维度丰富**：除常规表达指标外，强调效应相关与 DEG 排序（更贴近生物学优先级筛选的实用场景），并提供 parity、Bland-Altman、top-k 重叠、方向一致性等互补

诊断视角，使群体级预测的可信度与可解释性得到交叉验证。

## 8. 局限与不足

- **基线可比性存在结构性隐患**：所有对比方法均采用「官方/外部提供的评估输出」（supplied evaluation outputs）而非在同一划分、同一角色协议下重跑。虽然这避免了复现偏差，但不同方法可能使用了不同的对照选择、不同的细胞过滤与不同的评估实现，跨方法比较的公平性无法被论文自身完全保证。
- **消融仅在单一数据集上完成**：全部组件消融都在 Replogle RPE1 上执行，未在 Adamson（CRISPRi、UPR 通路）与 Norman（CRISPRa、双扰动）上重复。由于这三个数据集的扰动模态与效应结构差异明显，组件重要性是否可迁移缺乏直接证据。
- **缺少统计推断**：仅报告 5 个种子的均值 ± 样本标准差，未做配对检验、置信区间或效应量分析。在 RMSE 0.0499 vs 0.0861 这类差距较大处结论稳健，但在 Adamson/Norman 的效应指标上差距较小，是否显著不可知。
- **视图重叠破坏独立性假设**：论文的理论论证依赖两次抽样的视图误差条件均值为零且同分布。当条件细胞数较少、被迫使用有放回独立采样时，两个视图共享细胞，`η_a` 与 `η_b` 正相关，跨视图一致性项会被系统性高估，NLL 也可能被低估。论文虽「显式记录」该情形，但未给出相应的偏差校正或分层报告。
- **条件记忆的分布依赖**：门控记忆分支 `m_{p,s,d}` 由训练角色细胞的经验均值构造。若某测试条件在训练角色中细胞稀少、或与训练条件在背景/剂量上分布偏移，记忆项会退化为高方差估计，而模型以 0.75 的初始权重依赖它，可能损害冷启动条件下的表现。论文未报告按训练细胞数分层的性能曲线。
- **DEG 层绝对性能仍偏低**：最优结果 DEG F1 也仅约 0.18（K562）与 0.22（RPE1），DEG AP 约 0.26–0.31。说明从群体均值预测走向「可据以做生物学筛选的差异基因排序」仍有明显缺口，论文对此的讨论偏少。
- **评估止于转录组群体统计**：指标全部围绕表达均值、效应与 DEG 展开，未涉及蛋白丰度、通路活性、细胞表型或下游功能读出，因此「虚拟细胞」的宣称范围比实际验证范围更宽。
- **组合扰动验证有限**：pair interaction MLP 是架构中的关键非线性组件，但组合扰动的定量评估主要依赖 Norman 数据集的整体指标与个别案例图，缺少按「单扰动—双扰动」分层的系统性泛化测试（例如仅用单扰动训练、预测未见双扰动）。
- **超参数敏感性缺失**：视图大小、视图数量、基因权重温度 `ε`、门控初始化 `α=1.1`、损失权重（0.35/1.50/0.15/0.08/0.05）等均为固定值，除组件消融外未做敏感性扫描，读者难以判断结论对调参的依赖程度。
- **算力报告不完整**：仅说明单块 RTX 4090（24 GB）与约 3 小时训练，未区分是「单数据集单种子」还是「全部实验」；未给出 CPU/内存、总 GPU 小时、4 数据集 × 5 种子 × 消融的总训练次数，复现成本难以预估。
- **角色划分带来的数据效率代价**：train/val/support/test ≈ 50%/20%/10%/20% 的固定切分意味着仅一半细胞参与优化，另有 10% 专用于读出。对于本就细胞稀缺的条件，这一协议进一步压缩了可用样本，论文未讨论与替代划分（如交叉拟合）的权衡。

## 9. 结论与启示

- **方法论层面的核心贡献**是可迁移的：将「不可得的配对监督」替换为「同条件随机集合视图之间的群体统计量监督」，这一重构不依赖具体网络结构，原则上可移植到任何存在破坏性采样、无法获取前后配对的测量场景（如 Perturb-seq 之外的蛋白组扰动、多重成像扰动筛选）。
- **工程层面的可复用设计**包括：置换不变的「注意力摘要 + 离散度矩」集合编码器、掩码池化的扰动 token 组合编码、以及「经验效应记忆 + 门控神经残差」的显式先验融合策略。三者均可独立抽取用于其他条件响应预测任务。
- **评估层面的启示**：论文刻意将 Expression Pearson 与 Effect Pearson 并列，并指出前者在 Adamson/Norman 上由 GenePert 领先。这提示该领域的评测应避免只报告表达层相似度——高表达相关性可能仅来自共享的基线表达谱，而减去匹配对照后的效应指标与 DEG 排序才更贴近下游生物学筛选需求。
- **后续可推进的方向**：(1) 在统一协议下自行复现全部基线，消除外部输出的可比性隐患；(2) 将消融扩展到全部四个数据集，并引入统计显著性检验；(3) 针对小条件视图重叠问题设计去偏估计（如交叉拟合或视图相关性校正）；(4) 增加「单扰动训练 → 双扰动测试」的分层泛化评估；(5) 把评估从转录组群体均值扩展到通路活性与功能表型，以匹配「AI 虚拟细胞」的宣称范围。

## 10. 一句话总评

P2P 以「同条件随机集合视图」这一巧妙的监督单元重构，绕开了 Perturb-seq 中细胞配对不可观测的根本障碍，在四个数据集、六项指标上全面超越 GenePert、SLIM、Scouter 等基线，其集合编码器与「记忆门控残差」设计具备良好的可迁移性；但基线来自外部输出、消融仅在单数据集、DEG 绝对性能仍低、以及视图重叠对理论假设的侵蚀，使其结论的稳健边界仍需后续在统一协议下进一步确证。
